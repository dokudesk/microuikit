Card Component Documentation

The Card component provides a flexible container with optional fx-card-header, fx-card-body, and fx-card-footer. Uses flexbox column layout, theme variables for background, border, shadow, and transition.

Base usage (header + body + footer)

Card title

Some supporting text or content goes here. The card body can contain any HTML.

Footer text or actions 
<div class="fx-card">
  <div class="fx-card-header">
    <strong>Card title</strong>
  </div>
  <div class="fx-card-body">
    <p>Some supporting text...</p>
  </div>
  <div class="fx-card-footer">
    <small>Footer text or actions</small>
  </div>
</div>
  • fx-card is a flex column container; width: 100% by default � constrain with a wrapper or max-width.
  • Header has bottom border, footer has top border; all use theme padding and border variables.

Body only

A simple card with only a body. No header or footer.

<div class="fx-card">
  <div class="fx-card-body">
    <p>A simple card with only a body.</p>
  </div>
</div>

Header + body (no footer)

Section title

Content without a footer. Useful for info blocks or panels.

<div class="fx-card">
  <div class="fx-card-header"><strong>Section title</strong></div>
  <div class="fx-card-body"><p>Content...</p></div>
</div>

Body + footer (no header)

Content with a footer only. Good for call-to-action cards.

<div class="fx-card">
  <div class="fx-card-body"><p>Content...</p></div>
  <div class="fx-card-footer fx-d-flex fx-justify-center">
    <button type="button" class="fx-btn fx-btn-primary">Action</button>
  </div>
</div>

Card with link in footer

Article title

A short excerpt or description. Use semantic HTML: if the whole card is a link, wrap in <a> or use a link in the footer.

Quick customization

Custom border-radius and box-shadow via CSS variables.

<div class="fx-card fx-border fx-shadow-sm">
  ...
</div>
  • --fx-control-background-color card background
  • --fx-control-border-radius corner radius
  • --fx-shadow-sm shadow
  • --fx-card-padding-x, --fx-card-padding-y padding for header, body, footer

What the CSS package covers

  • Card: .fx-card � flex column, full width, background, border, border-radius, box-shadow, overflow hidden, transition.
  • Header: .fx-card-header � padding (top, left, right), no bottom padding; bottom border.
  • Body: .fx-card-body � padding on all sides.
  • Footer: .fx-card-footer � padding (bottom, left, right), no top padding; top border.

Accessibility notes

  • Use semantic headings (h2, h3) in the header when the card represents a section or article.
  • If the entire card is clickable, use a single <a> or <button> with sufficient hit area and a clear label; avoid multiple links that are hard to distinguish.
  • For card lists, consider role="list" on the container and role="listitem" on each card if they are not already list markup.
