Checkbox Component Documentation

The Checkbox component styles a native input[type="checkbox"] with a custom visual box and tick. It uses fx-checkbox-frame as wrapper, with the input and a label[for]. Supports checked, focus-visible, disabled, readonly, invalid, and valid states.

Base usage

<div class="fx-checkbox-frame">
  <input id="cb-base" type="checkbox" class="fx-checkbox" />
  <label for="cb-base">Option</label>
</div>

Checked and unchecked

<input type="checkbox" class="fx-checkbox" />
<input type="checkbox" class="fx-checkbox" checked />
  • Checked state uses --fx-checkbox-checked-background-color and --fx-checkbox-tick-color for the tick icon.

Focus-visible

<input type="checkbox" class="fx-checkbox" />
<label for="...">Focus me</label>
  • Focus ring on the custom box uses --fx-focus-ring-outline-width, --fx-focus-ring-color, --fx-focus-ring-outline-offset.

Disabled state

<input type="checkbox" class="fx-checkbox" disabled />
<input type="checkbox" class="fx-checkbox" disabled checked />
  • Label and box use muted color and --fx-disabled-control-opacity.

Readonly state

<input type="checkbox" class="fx-checkbox" readonly checked />
  • readonly disables pointer events so the value cannot be toggled by click; use when the value is display-only or controlled elsewhere.

Validation states (invalid / valid)

<input type="checkbox" class="fx-checkbox" invalid />
<input type="checkbox" class="fx-checkbox" valid checked />

<!-- Invalid and disabled together -->
<input type="checkbox" class="fx-checkbox" invalid disabled />
<input type="checkbox" class="fx-checkbox" invalid disabled checked />
  • Set invalid or valid (e.g. via JS after validation). Uses --fx-invalid-border-color, --fx-invalid-color, --fx-valid-border-color, --fx-valid-color.
  • When both invalid and disabled are set, the result combines invalid border/color with disabled opacity, cursor, and non-interactivity (see the two examples above).

Quick customization

<div class="fx-checkbox-frame" style="--fx-checkbox-size: 1.25rem;">...</div>
<div class="fx-checkbox-frame" style="--fx-checkbox-size: 2rem; --fx-checkbox-border-radius: 6px;">...</div>
  • --fx-checkbox-size box size
  • --fx-checkbox-border-radius corner radius
  • --fx-checkbox-checked-background-color filled box when checked
  • --fx-checkbox-tick-color tick icon color
  • --fx-checkbox-tick-svg tick mask image
  • --fx-border-width, --fx-border-color, --fx-control-background-color
  • --fx-focus-ring-* focus outline
  • --fx-control-padding-x gap between box and label
  • --fx-text-color, --fx-text-muted-color, --fx-disabled-control-opacity
  • --fx-transition animation

What the CSS package covers

  • Frame: .fx-checkbox-frame � wrapper with margin: 0 and layout for input + label.
  • Input: input[type="checkbox"].fx-checkbox � visually hidden (clip, opacity), positioned for accessibility.
  • Label: label[for] � cursor, font, color, padding; ::before = custom box (size, border, background, border-radius); ::after = tick (mask, color when checked).
  • Checked: :checked + label::before background/border; tick visible via ::after.
  • Focus: :focus-visible:not(:disabled) + label::before � outline and offset.
  • Disabled: label color/opacity/cursor/pointer-events; box and tick use muted color and opacity.
  • Readonly: [readonly] � pointer-events none on input and label.
  • Invalid/Valid: [invalid] and [valid] � label color, box border, and when checked box background/tick colors.

Accessibility notes

  • Always use a label[for] that matches the input id so the checkbox is properly associated and clickable.
  • The native input is visually hidden but remains focusable and announced by screen readers; the custom box is purely visual.
  • For validation, set invalid/valid in sync with aria-invalid and provide error/success messages for screen readers.
