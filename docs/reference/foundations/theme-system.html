Theme System

Flexa supports light, dark, and auto modes through root attributes and media-query-aware token overrides.

Theme contract

<html data-theme="light">...</html>
<html data-theme="dark">...</html>
<html data-theme="auto">...</html>
  • data-theme="auto" follows system preference via prefers-color-scheme.
  • Theme changes cascade through semantic tokens (text, background, border, controls).
