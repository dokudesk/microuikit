Core Package Introduction

This section documents Flexa's non-component layer: foundations, utilities, layout primitives, and cross-cutting behaviors for enterprise-ready design systems.

Stable APIUtility-firstRTL/LTR awareTheme-ready

What is included

  • Global foundations: tokens, reset, base typography, accessibility defaults.
  • Composable utility classes for layout, spacing, color, border, radius, shadow, and text flow.
  • Responsive grid system with predictable breakpoints and logical direction support.
  • Validation and content helpers for production forms and content-heavy interfaces.

Quick start markup

<link rel="stylesheet" href="dist/css/core.css" />
<link rel="stylesheet" href="dist/css/themes/theme-default.css" />

<main class="fx-container">
  <section class="fx-row fx-gx-3 fx-gy-3">
    <article class="fx-col-12 fx-col-md-6 fx-p-3 fx-border fx-rounded">...</article>
    <article class="fx-col-12 fx-col-md-6 fx-p-3 fx-border fx-rounded">...</article>
  </section>
</main>
Use utility composition for page-level layout and reserve component classes for interactive UI primitives.
