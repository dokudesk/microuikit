Accessibility

Flexa provides a consistent baseline for accessible UIs: global focus styles driven by tokens, optional reduced-motion behavior, and visibility utilities that work with layout and screen readers. Components use focus-visible where appropriate so keyboard users get clear feedback without forcing focus rings on mouse click.

Custom focus ring
<div style="--fx-focus-ring-color: var(--fx-danger); 
  --fx-focus-ring-outline-width: 3px; 
  --fx-focus-ring-outline-offset: 4px;">
  <button type="button" class="fx-btn fx-btn-secondary">Button with custom focus</button>
  <input type="text" class="fx-input" value="Input with custom focus" style="width: auto;" />
</div>
  • Override focus ring appearance by setting the focus tokens on a parent.
  • Focus ring uses outline with --fx-focus-ring-outline-width, --fx-focus-ring-outline-offset, and --fx-focus-ring-color.
  • Components can override focus (e.g. checkbox and radio show the ring on the custom box; framed inputs show focus via border).
