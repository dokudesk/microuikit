How it works
  • Standard (Firefox, etc.) * gets scrollbar-width: var(--fx-scrollbar-width) and scrollbar-color: var(--fx-scrollbar-color) var(--fx-background-color) (thumb and track).
  • WebKit (Chrome, Edge, Safari) *::-webkit-scrollbar uses --fx-edge-scrollbar-width and --fx-edge-scrollbar-height for bar size; *::-webkit-scrollbar-track uses --fx-background-color and --fx-border-radius; *::-webkit-scrollbar-thumb uses --fx-scrollbar-color and --fx-border-radius; thumb hover uses --fx-scrollbar-hover-color; *::-webkit-scrollbar-corner uses --fx-background-color.
  • Theme files override --fx-scrollbar-color and --fx-scrollbar-hover-color for dark mode so scrollbars stay readable on dark backgrounds.
