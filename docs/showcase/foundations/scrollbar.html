How it works
  • Standard browsers (e.g., Firefox)
    The following settings apply to all elements (*):
    • scrollbar-width is set using the variable --fx-scrollbar-width.
    • scrollbar-color defines the scrollbar colors using --fx-scrollbar-color for the thumb and --fx-background-color for the track.
  • WebKit browsers (Chrome, Edge, Safari)
    Scrollbars are customized using WebKit pseudo-elements:
    • *::-webkit-scrollbar sets the scrollbar size using --fx-edge-scrollbar-width and --fx-edge-scrollbar-height.
    • *::-webkit-scrollbar-track defines the track background and border radius using --fx-background-color and --fx-border-radius.
    • *::-webkit-scrollbar-thumb sets the thumb color and border radius using --fx-scrollbar-color and --fx-border-radius.
    • When hovering over the thumb, its color changes to --fx-scrollbar-hover-color.
    • *::-webkit-scrollbar-corner uses --fx-background-color for the corner area.
  • Dark mode support
    Theme files override --fx-scrollbar-color and --fx-scrollbar-hover-color in dark mode so the scrollbar remains visible and readable on dark backgrounds.
