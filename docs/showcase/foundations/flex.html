Flex

Use mk-d-flex or mk-d-inline-flex (see Layout basics) to create a flex container, then control direction, wrap, justify-content, align-items, align-content, and flex grow/shrink on children. Shortcuts mk-center (grid + place-items center), mk-center-x / mk-center-y (flex + justify/align center), and mk-flex-row (flex row nowrap) are available.
