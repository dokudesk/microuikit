Flex

Use fx-d-flex or fx-d-inline-flex (see Layout basics) to create a flex container, then control direction, wrap, justify-content, align-items, align-content, and flex grow/shrink on children. Shortcuts fx-center (grid + place-items center), fx-center-x / fx-center-y (flex + justify/align center), and fx-flex-row (flex row nowrap) are available.
