Spacing

Margin and padding use a shared scale: 0, 1 (0.25rem), 2 (0.5rem), 3 (1rem), 4 (1.5rem), 5 (3rem). Sides: t, b, l, r, x (left+right), y (top+bottom), or logical s/e (start/end) for RTL-friendly spacing. Gap utilities use the same scale for flex/grid.
