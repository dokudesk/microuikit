Direction

Direction supports left-to-right (LTR) and right-to-left (RTL) layouts with the same markup. Direction is set on the document root; CSS logical properties and direction-aware tokens ensure components and utilities flip correctly for RTL locales or mixed-direction content.

Setting direction

Set the page or app direction on <html>. Flexa respects the standard dir attribute and also data-dir, direction, and data-direction so you can integrate with existing backends or URL-based locale switching. 

<html dir="ltr">...</html>
<html dir="rtl">...</html>
<!-- Also: data-dir, direction, data-direction -->

With flexa.js loaded, the Flexa.Direction helper lets you switch direction from JavaScript and listen for changes: 

// Switch direction
Flexa.Direction.set('ltr');
Flexa.Direction.set('rtl');

// Read current direction
const dir = Flexa.Direction.get(); // 'ltr' or 'rtl'

// React to direction changes
document.documentElement.addEventListener('flexa:direction-change', (event) => {
  console.log('Direction changed to', event.detail.direction);
});
Direction tokens

Theme and core CSS define three tokens that switch when the root direction is RTL:

  • --fx-direction is ltr or rtl; html uses direction: var(--fx-direction) so the whole document follows.
  • --fx-text-start and --fx-text-end are left / right in LTR and right / left in RTL. Utilities like fx-float-start and fx-float-end use these so “start” and “end” flip with direction.

Components use logical properties (e.g. inset-inline-start, padding-inline-end) and direction-aware values so labels, icons, and spacing align correctly in both directions without extra classes.

Typography and locale

Theme files can define separate font stacks for LTR and RTL so you can pick script-appropriate fonts (e.g. for Arabic or Hebrew). --fx-font-family-base resolves to --fx-font-family-ltr or --fx-font-family-rtl depending on the root direction; --fx-font-size-base and --fx-font-weight-base use the same pattern. Set these in your theme or a custom flexa-theme-*.css for each locale if needed.

Direction override classes

For mixed-direction layouts (e.g. an RTL page with an LTR quote or code block), use fx-ltr or fx-rtl on a wrapper. They set direction: ltr or direction: rtl with !important so that subtree uses the chosen direction regardless of the parent.

Forced LTR (Right-to-left): text starts from left
Forced RTL (Left-to-right): text starts from right
<div class="fx-ltr fx-text-start">Forced LTR (Right-to-left): text starts from left</div>
<div class="fx-rtl fx-text-start">Forced RTL (Left-to-right): text starts from right</div>
Text alignment and float utilities

fx-text-start and fx-text-end set text-align: start and text-align: end so alignment follows direction. fx-float-start and fx-float-end use --fx-text-start and --fx-text-end so floated content appears on the correct side in both LTR and RTL. Prefer these over hard-coded left/right so the same layout works in all locales.
