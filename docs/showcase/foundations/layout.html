Layout

Low-level layout is handled by display, position, float, and vertical-align utilities. Use them to structure blocks, inline content, flex/grid parents, or legacy table layouts. Floats use --fx-text-start and --fx-text-end so they flip with RTL.

Display
  • Block/inline: fx-d-block, fx-d-inline, fx-d-inline-block, fx-d-none.
  • Flex: fx-d-flex, fx-d-inline-flex (see Flex utilities for alignment and wrap).
  • Grid: fx-d-grid, fx-d-inline-grid (see Grid system for columns and gutters).
  • Table: fx-d-table, fx-d-table-row, fx-d-table-cell for table-like layout without semantic table markup.
