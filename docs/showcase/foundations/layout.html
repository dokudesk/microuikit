Layout

Low-level layout is handled by display, position, float, and vertical-align utilities. Use them to structure blocks, inline content, flex/grid parents, or legacy table layouts. Floats use --mk-text-start and --mk-text-end so they flip with RTL.

Display
  • Block/inline: mk-d-block, mk-d-inline, mk-d-inline-block, mk-d-none.
  • Flex: mk-d-flex, mk-d-inline-flex (see Flex utilities for alignment and wrap).
  • Grid: mk-d-grid, mk-d-inline-grid (see Grid system for columns and gutters).
  • Table: mk-d-table, mk-d-table-row, mk-d-table-cell for table-like layout without semantic table markup.
