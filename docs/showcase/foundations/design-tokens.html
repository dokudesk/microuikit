Design Tokens (CSS Variables)

Flexa exposes a structured token system through CSS custom properties under :root and theme/data-direction scopes.

Primary token groups

Color
--fx-text-color, --fx-background-color - Semantic system colors and UI state colors
Typography
--fx-font-size-base, --fx-line-height-base - Readable text scale and rhythm
Spacing
--fx-gutter-width, --fx-control-padding-x - Consistent spacing across utilities and controls
Shape
--fx-control-border-radius, --fx-border-width - Rounded corners, borders, and visual density
