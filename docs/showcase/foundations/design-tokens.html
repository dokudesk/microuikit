Design tokens

Flexa’s look and behavior are driven by design tokens: CSS custom properties (variables) that you can override globally, per theme, or per component. Tokens live on :root and in theme files; light, dark, and auto modes (and RTL/LTR) are supported via scoped overrides.

Where tokens are defined
  • Core. The base set of tokens is defined in flexa.css under :root (SVG assets, typography, palette, and fallbacks for semantic and control tokens).
  • Themes. Theme files such as flexa-theme-default.css define the default light values (colors, spacing, radius, focus ring, etc.) and override them for data-theme="dark" and, inside @media (prefers-color-scheme: dark), for data-theme="auto".
  • Custom themes. You can add your own flexa-theme-*.css files that redefine the same token names so one codebase supports multiple brands or locales without changing the core CSS.
Token categories

Tokens are grouped by purpose. Override only what you need; components and utilities reference these variables so a single change applies everywhere.

  • Assets. SVG masks for icons (spinner, eye open/off, arrow down, checkbox tick). Names: --fx-spinner-svg, --fx-eye-open-svg, --fx-eye-off-svg, --fx-arrow-down-svg, --fx-checkbox-tick-svg.
  • Typography. Font family (with separate LTR/RTL tokens and a resolved --fx-font-family-base), base size and weight, line height. Direction-aware themes can set --fx-font-family-rtl and related variables for RTL locales.
  • Color palette. Raw hues (e.g. --fx-primary, --fx-success, grays) and semantic tokens: --fx-text-color, --fx-background-color, --fx-border-color, --fx-valid-color, --fx-invalid-color, --fx-focus-ring-color, and link, placeholder, muted, and control-specific colors.
  • Component sizing and spacing. Control height, padding, border radius, card padding; checkbox and radio size; select option height; gutter; border width; transition; focus ring width/offset; disabled opacity; scrollbar dimensions.
  • Direction. --fx-direction, --fx-text-start, --fx-text-end for RTL/LTR-aware layout and alignment (typically set by the theme or direction utilities).
Overriding tokens

You can override any token at a higher scope (e.g. :root, html[data-theme="dark"], or a wrapper class) or inline on a single element. Inline overrides are useful for one-off styling or demos.

For site-wide or theme-wide changes, override tokens in your own stylesheet (loaded after the theme) or in a custom flexa-theme-*.css file. That keeps the core package untouched and makes it easy to maintain multiple themes or locales.
