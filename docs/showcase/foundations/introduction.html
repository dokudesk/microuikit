Introduction

MicroUIKit is a compact CSS package designed for micro UIs and applications that require a small, predictable UI layer with fast loading times.
It keeps bundle size low while giving you full control over standard HTML components, foundations, and utilities-without the overhead of a full framework.
It is designed with component-based architecture, full RTL/LTR support, WCAG 2.1 accessibility compliance, and powered by CSS Cascade Layers for predictable styling and seamless theme switching.

What MicroUIKit provides
  • Small footprint. The core CSS is kept minimal so pages load quickly and stay easy to reason about.
  • Standard HTML, styled. Buttons, inputs, selects, checkboxes, radios, textareas, and cards are standard elements; MicroUIKit styles them via classes and tokens so you can customize behavior and appearance without rebuilding components.
  • Full RTL and LTR support. Layout and components respect text direction and logical properties, so the same markup works for left-to-right and right-to-left languages.
  • Theme modes. Light, dark, and system (OS preference) are supported out of the box via data-theme and design tokens.
  • Custom themes. Use microuikit-theme-*.css files to define brand or product-specific themes. Load one theme per context or locale so multilingual and multi-brand UIs share the same core and swap only the theme layer.
Quick start
  1. Include the core stylesheet (microuikit.css) along with a default or custom theme (microuikit-theme-*.css).
  2. Structure your content using semantic HTML, applying MicroUIKit classes only where layout or components are required.
  3. Include the JavaScript file (microuikit.js) to enable core interactive behaviors (for example, theme switching and interactive toggles).
<link rel="stylesheet" href="[asset path]/css/microuikit.css" />
<link rel="stylesheet" href="[asset path]/css/themes/microuikit-theme-default.css" />
<main>
  <!-- Your content and MicroUIKit classes -->
</main>
<script src="[asset path]/js/microuikit.js"></script>
