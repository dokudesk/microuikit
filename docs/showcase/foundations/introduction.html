Introduction

Flexa is a minimal CSS package built for micro-systems and applications that need a small, predictable UI layer and fast load times.
It keeps bundle size low while giving you full control over standard HTML components, foundations, and utilities-without the overhead of a full framework.
It is designed with component-based architecture, full RTL/LTR support, WCAG 2.1 accessibility compliance, and powered by CSS Cascade Layers for predictable styling and seamless theme switching.

What Flexa provides
  • Small footprint. The core CSS is kept minimal so pages load quickly and stay easy to reason about.
  • Standard HTML, styled. Buttons, inputs, selects, checkboxes, radios, textareas, and cards are standard elements; Flexa styles them via classes and tokens so you can customize behavior and appearance without rebuilding components.
  • Full RTL and LTR support. Layout and components respect text direction and logical properties, so the same markup works for left-to-right and right-to-left languages.
  • Theme modes. Light, dark, and auto (system preference) are supported out of the box via data-theme and design tokens.
  • Custom themes. Use flexa-theme-*.css files to define brand or product-specific themes. Load one theme per context or locale so multilingual and multi-brand UIs share the same core and swap only the theme layer.
Quick start
  1. Include the core stylesheet (flexa.css) along with a default or custom theme (flexa-theme-*.css).
  2. Structure your content using semantic HTML, applying Flexa classes only where layout or components are required.
  3. Include the JavaScript file (flexa.js) to enable core interactive behaviors (for example, theme switching and interactive toggles).
<link rel="stylesheet" href="[asset path]/css/flexa.css" />
<link rel="stylesheet" href="[asset path]/css/themes/flexa-theme-default.css" />
<main>
  <!-- Your content and Flexa classes -->
</main>
<script src="[asset path]/js/flexa.js"></script>
