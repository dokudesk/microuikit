Accessibility and Motion

Flexa core includes focus visibility defaults and reduced-motion-aware behavior for accessible interaction patterns.

Focusable link
Focus outlines are controlled by --fx-focus-ring-outline-width, --fx-focus-ring-outline-offset, and --fx-focus-ring-color.

Motion handling

  • Smooth scrolling is enabled only when users allow motion (prefers-reduced-motion: no-preference).
  • Core transitions are tokenized through --fx-transition for centralized control.
  • For sensitive interfaces, keep transitions subtle and avoid animation-only state communication.
