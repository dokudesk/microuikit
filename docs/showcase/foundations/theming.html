Theming

Theme lets you switch between light and dark appearance without changing component markup. Themes are applied by setting an attribute on the document root; token overrides in theme files handle colors and other semantic values so components and utilities stay consistent. Three modes are supported: light, dark, and auto (system preference).

Theme modes

Set the theme on <html> with data-theme (or theme). Three modes are supported:

  • light. data-theme="light" uses the default light token values defined in the theme file (text, background, border, controls, links, validation colors, etc.).
  • dark. data-theme="dark" applies dark token overrides so the same components render with dark backgrounds and light text. The theme file defines these under html[data-theme=dark] (and html[theme=dark] for compatibility).
  • auto. data-theme="auto" follows the user’s system preference. When prefers-color-scheme: dark matches, the theme file applies the same dark overrides as dark; otherwise the light defaults are used.
<html data-theme="light">...</html>
<html data-theme="dark">...</html>
<html data-theme="auto">...</html>
How theme files work

A theme file (e.g. microuikit-theme-default.css) defines the default tokens in :root and then overrides a subset of tokens for dark mode. Dark overrides are applied in two places:

  • Directly for html[data-theme=dark] (and html[theme=dark]), so an explicit data-theme="dark" always gets dark styling.
  • Inside @media (prefers-color-scheme: dark) for html[data-theme=auto] (and html[theme=auto]), so when the system prefers dark, auto receives the same dark token values.

Only semantic tokens that need to change between light and dark are overridden (text, background, border, control background, link and focus colors, scrollbar, validation colors, etc.). Components and utilities reference these variables, so no class changes are required when the theme switches.

Custom themes

You can ship your own theme by creating a microuikit-theme-*.css file that defines the same token names. Load it instead of (or after) the default theme so your brand or product colors apply across the app. For multi-brand or multilingual setups, load one theme per context or locale while keeping the same core microuikit.css and markup.

Switching the theme at runtime

To let users change the theme (e.g. via a control in the UI), set data-theme (or theme) on document.documentElement to light, dark, or auto. When you include microuikit.js, the global MicroUIKit.Theme helper exposes a small API so you don’t need to manage attributes manually.

Use MicroUIKit.Theme.set() to switch, MicroUIKit.Theme.get() to read the current value, and listen for the microuikit:theme-change event to react in your own code: 

// Switch theme
MicroUIKit.Theme.set('light');
MicroUIKit.Theme.set('dark');
MicroUIKit.Theme.set('auto'); // follow system preference

// Read current theme
const current = MicroUIKit.Theme.get(); // 'light', 'dark', or 'auto'

// React to theme changes (e.g. update toggle UI)
document.documentElement.addEventListener('microuikit:theme-change', (event) => {
  console.log('Theme changed to', event.detail.theme);
});
