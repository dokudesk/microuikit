Select Component

The Select component styles a native select element with custom appearance, arrow icon, and support for focus, validation (invalid/valid), disabled state, and multiple selection.

Base usage
<select class="fx-select">
  <option>Option A</option>
  <option>Option B</option>
  <option>Option C</option>
</select>
  • Without fx-select-frame, the select uses the browser's native appearance.
With frame and arrow (mask-based)
<div class="fx-select-frame">
  <select id="sel-frame" class="fx-select">
    <option value="">Choose...</option>
    <option>Apple</option>
    <option>Banana</option>
    <option>Cherry</option>
  </select>
  <span class="fx-select-arrow" aria-hidden="true"></span>
</div>
  • Arrow is rendered with mask + --fx-select-arrow-color so it follows the theme (e.g. dark mode).
  • fx-select-arrow is decorative and has pointer-events: none; clicks go to the select.

<div class="fx-select-frame">
  <select class="fx-select" valid disabled>
    <option>Valid + disabled</option>
  </select>

</div>
  • Use invalid/valid for state-driven validation styling; these states apply semantic border/text colors via --fx-invalid-border-color, --fx-invalid-color, --fx-valid-border-color, and --fx-valid-color.
  • ARIA mapping is fully supported: aria-invalid="true" uses invalid styling, and aria-invalid="false" uses valid styling, matching the visual behavior of invalid/valid.
  • When validation and disabled states are combined, disabled behavior remains dominant for interaction (opacity and non-interactivity), while validation cues are preserved where applicable.
Disabled state
<div class="fx-select-frame">
  <select class="fx-select" disabled> 
    <option>Disabled</option> 
  </select>
  <span class="fx-select-arrow" aria-hidden="true"></span>
</div>
  • --fx-text-muted-color defines the disabled text tone for the field and selected options.
  • --fx-disabled-control-opacity controls visual de-emphasis for disabled select states while preserving layout and readability.

  <select class="fx-select" style="--fx-control-height: 4rem; --fx-control-border-radius: 999px;">
    <option>Tall and rounded</option>
    <option>Option 2</option>
  </select>
  <span class="fx-select-arrow" aria-hidden="true"></span>
</div>

<div class="fx-select-frame" style="--fx-select-arrow-color: var(--fx-primary);">
  <select class="fx-select" style="--fx-control-padding-x: 2rem;">
    <option>Custom padding and arrow</option>
    <option>Option 2</option>
  </select>
  <span class="fx-select-arrow" aria-hidden="true"></span>
</div>

<div class="fx-select-frame" style="--fx-select-arrow-color: var(--fx-danger);">
  <select class="fx-select" 
    style="--fx-control-background-color: var(--fx-background-muted-color);
    --fx-border-color: var(--fx-danger); 
    --fx-text-color: var(--fx-danger);">
    <option>Custom surface and border</option>
    <option>Option 2</option>
  </select>
  <span class="fx-select-arrow" aria-hidden="true"></span>
</div>
  • --fx-control-height, --fx-control-padding-x, --fx-control-padding-y, and --fx-control-border-radius control field sizing and shape.
  • --fx-border-width, --fx-border-color, --fx-control-background-color, and --fx-text-color define base field appearance.
  • --fx-focus-ring-color controls focus border color inside .fx-select-frame.
  • --fx-select-arrow-color controls the decorative arrow color in frame mode. Set it on .fx-select-frame (or an ancestor), not on the select, so the arrow element can inherit it.
  • --fx-select-selected-option-text-color and --fx-select-selected-option-background-color style selected option rows.
  • --fx-invalid-border-color, --fx-invalid-color, --fx-valid-border-color, --fx-valid-color, and --fx-disabled-control-opacity control validation/disabled states.
  • --fx-transition sets motion timing for interactive state changes.
What the CSS package covers
  • Base. .fx-select applies height, padding, typography, color, background, border, border-radius, and transition via --fx-control-height, --fx-control-padding-x/--fx-control-padding-y, --fx-control-background-color, --fx-border-width, --fx-border-color, --fx-control-border-radius, and --fx-transition.
  • Options. option uses --fx-select-option-height and --fx-text-color. option:checked uses --fx-select-selected-option-text-color and --fx-select-selected-option-background-color. When the select is disabled, checked options use --fx-text-muted-color and --fx-background-muted-color.
  • Validation and disabled state. [invalid] and [aria-invalid="true"] apply invalid border and text colors via --fx-invalid-*; [valid] and [aria-invalid="false"] apply valid colors via --fx-valid-*. [disabled] applies muted text and --fx-disabled-control-opacity.
  • Frame. .fx-select-frame wraps the select. The select has outline: none; focus border uses --fx-focus-ring-color. When .fx-select-arrow is present, the select has appearance: none and extra end padding so the native dropdown arrow is replaced by the custom arrow.
  • Select arrow. .fx-select-arrow is absolutely positioned at the block end. Its ::before pseudo-element shows the icon (mask --fx-arrow-down-svg, color --fx-select-arrow-color or --fx-control-icon-color; the variable is read from the frame/ancestors, not from the select). The arrow is hidden when the select has the multiple attribute.
  • Multiple mode. When multiple is set, the select has transparent border and standard padding; the frame provides the visible border and padding. Frame border state for focus, invalid, valid, and disabled is driven by :has() selectors on the select.
Accessibility notes
  • Associate a visible or off-screen label with the select via for and matching id so the control is announced and the label click area activates the select.
  • Expose validation state to assistive technologies and drive styling by using the invalid and valid attributes, or aria-invalid="true" and aria-invalid="false".
  • Mark the custom dropdown arrow (e.g. .fx-select-arrow) with aria-hidden="true" so it is ignored by assistive technologies.
