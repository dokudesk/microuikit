Glass Component

The Glass component provides a translucent background with blur and border effects.

What the CSS package covers
  • .mk-glass uses background-color with color-mix(..., transparent) for translucency, applies backdrop-filter: blur(20px) and semi-transparent border.
  • For the blur effect to be visible, place .mk-glass above a background (gradient, image, or any content).
