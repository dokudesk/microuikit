Card Component

The Card component provides a flexible content container with optional header, body, and footer regions. It is useful for summaries, content groups, and dashboard blocks while staying fully theme-aware.

Base usage (header + body + footer)
Card title

Some supporting text or content goes here. The card body can contain any HTML.

Footer text or actions 
<div class="fx-card">
  <div class="fx-card-header">
    <strong>Card title</strong>
  </div>
  <div class="fx-card-body">
    <p>Some supporting text...</p>
  </div>
  <div class="fx-card-footer">
    <small>Footer text or actions</small>
  </div>
</div>
  • .fx-card is a flex-column container and uses width: 100% by default; constrain width via wrapper or max-width.
  • Header/footer separators are optional and commonly added with utility classes like fx-border-bottom and fx-border-top.
Body only

A simple card with only a body. No header or footer.

<div class="fx-card">
  <div class="fx-card-body">
    <p>A simple card with only a body.</p>
  </div>
</div>
Header + body (no footer)
Section title

Content without a footer. Useful for info blocks or panels.

<div class="fx-card">
  <div class="fx-card-header"><strong>Section title</strong></div>
  <div class="fx-card-body"><p>Content...</p></div>
</div>
Body + footer (no header)

Content with a footer only. Good for call-to-action cards.

<div class="fx-card">
  <div class="fx-card-body"><p>Content...</p></div>
  <div class="fx-card-footer fx-d-flex fx-justify-center">
    <button type="button" class="fx-btn fx-btn-primary">Action</button>
  </div>
</div>

Quick customization

Rounded corners via --fx-control-border-radius.

Elevated appearance via fx-shadow-sm.

Custom surface and spacing tokens.

<div class="fx-card" style="--fx-control-border-radius: 1rem;">
  <div class="fx-card-body">...</div>
</div>

<div class="fx-card fx-shadow-sm">
  <div class="fx-card-body">...</div>
</div>

<div class="fx-card" style="--fx-control-background-color: var(--fx-background-muted-color); --fx-card-padding-y: 2.5rem;">
  <div class="fx-card-body">...</div>
</div>
  • --fx-control-background-color controls card surface color.
  • --fx-control-border-radius controls card corner roundness.
  • fx-shadow-* utilities control elevation depth.
  • --fx-card-padding-x and --fx-card-padding-y control spacing for header, body, and footer slots.
  • --fx-border-color and --fx-border-width control border appearance.
What the CSS package covers
  • Base. .fx-card applies flex column layout, full width, background (--fx-control-background-color), border (--fx-border-width, --fx-border-color), border-radius (--fx-control-border-radius), transition (--fx-transition), box-shadow (--fx-box-shadow), and overflow: hidden.
  • Header slot. .fx-card-header uses --fx-card-padding-y and --fx-card-padding-x with no bottom padding so content aligns to the top of the card.
  • Body slot. .fx-card-body uses the same card padding on all sides for the main content area.
  • Footer slot. .fx-card-footer uses card padding with no top padding so actions align to the bottom of the card.
  • Dividers. Header and footer separators are not included by default. Apply utility classes such as fx-border-bottom or fx-border-top to the header or footer when visual separation is required.
