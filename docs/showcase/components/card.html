Card Component

The Card component provides a flexible content container with optional header, body, and footer regions. It is useful for summaries, content groups, and dashboard blocks while staying fully theme-aware.

Base usage (header + body + footer)
Card title

Some supporting text or content goes here. The card body can contain any HTML.

Footer text or actions 
<div class="mk-card">
  <div class="mk-card-header">
    <strong>Card title</strong>
  </div>
  <div class="mk-card-body">
    <p>Some supporting text...</p>
  </div>
  <div class="mk-card-footer">
    <small>Footer text or actions</small>
  </div>
</div>
  • .mk-card is a flex-column container and uses width: 100% by default; constrain width via wrapper or max-width.
  • Header/footer separators are optional and commonly added with utility classes like mk-border-bottom and mk-border-top.
Body only

A simple card with only a body. No header or footer.

<div class="mk-card">
  <div class="mk-card-body">
    <p>A simple card with only a body.</p>
  </div>
</div>
Header + body (no footer)
Section title

Content without a footer. Useful for info blocks or panels.

<div class="mk-card">
  <div class="mk-card-header"><strong>Section title</strong></div>
  <div class="mk-card-body"><p>Content...</p></div>
</div>
Body + footer (no header)

Content with a footer only. Good for call-to-action cards.

<div class="mk-card">
  <div class="mk-card-body"><p>Content...</p></div>
  <div class="mk-card-footer mk-d-flex mk-justify-center">
    <button type="button" class="mk-btn mk-btn-primary">Action</button>
  </div>
</div>

Quick customization

Rounded corners via --mk-control-border-radius.

Elevated appearance via mk-shadow-sm.

Custom surface and spacing tokens.

<div class="mk-card" style="--mk-control-border-radius: 1rem;">
  <div class="mk-card-body">...</div>
</div>

<div class="mk-card mk-shadow-sm">
  <div class="mk-card-body">...</div>
</div>

<div class="mk-card" style="--mk-control-background-color: var(--mk-background-muted-color); --mk-card-padding-y: 2.5rem;">
  <div class="mk-card-body">...</div>
</div>
  • --mk-control-background-color controls card surface color.
  • --mk-control-border-radius controls card corner roundness.
  • mk-shadow-* utilities control elevation depth.
  • --mk-card-padding-x and --mk-card-padding-y control spacing for header, body, and footer slots.
  • --mk-border-color and --mk-border-width control border appearance.
What the CSS package covers
  • Base. .mk-card applies flex column layout, full width, background (--mk-control-background-color), border (--mk-border-width, --mk-border-color), border-radius (--mk-control-border-radius), transition (--mk-transition), box-shadow (--mk-box-shadow), and overflow: hidden.
  • Header slot. .mk-card-header uses --mk-card-padding-y and --mk-card-padding-x with no bottom padding so content aligns to the top of the card.
  • Body slot. .mk-card-body uses the same card padding on all sides for the main content area.
  • Footer slot. .mk-card-footer uses card padding with no top padding so actions align to the bottom of the card.
  • Dividers. Header and footer separators are not included by default. Apply utility classes such as mk-border-bottom or mk-border-top to the header or footer when visual separation is required.
