Button Component

The Button component is used to create interactive buttons.

Base usage
<button type="button" style="width: 150px;" class="fx-btn">Base button</button>
Theme colors
<button type="button" style="width: 150px;" class="fx-btn fx-btn-primary">Primary</button>
<button type="button" style="width: 150px;" class="fx-btn fx-btn-secondary">Secondary</button>

<button type="button" style="width: 150px;" class="fx-btn fx-btn-info">Info</button>
<button type="button" style="width: 150px;" class="fx-btn fx-btn-warning">Warning</button>
<button type="button" style="width: 150px;" class="fx-btn fx-btn-danger">Danger</button>
<button type="button" style="width: 150px;" class="fx-btn fx-btn-light">Light</button>
<button type="button" style="width: 150px;" class="fx-btn fx-btn-dark">Dark</button>
Disabled and loading states
<button type="button" style="width: 150px;" class="fx-btn fx-btn-secondary" disabled>Disabled</button>
<button type="button" style="width: 150px;" class="fx-btn fx-btn-primary" aria-busy="true" aria-label="Submitting">
  Submitting
</button>
Form actions (button type)
<button type="button" style="width: 150px;" class="fx-btn fx-btn-primary">Action</button>
<button type="submit" style="width: 150px;" class="fx-btn fx-btn-success">Submit</button>
<button type="reset" style="width: 150px;" class="fx-btn fx-btn-warning">Reset</button>
  • Always set type explicitly to avoid accidental submits.
  • Use submit and reset only inside forms.
JavaScript helper (busy state)
// Ensure flexa.js is loaded
const btn = document.getElementById("save-btn");
Flexa.ButtonBusy.enableBusy(btn, "Saving");
setTimeout(() => Flexa.ButtonBusy.disableBusy(btn), 1200);
  • Dispatches flexa:button-busy on the button element.
  • Provide a readable label for assistive technologies.
Quick customization
<button class="fx-btn fx-btn-success"
  style="--fx-control-height: 3.5rem; --fx-control-border-radius: 999px;">
  Compact & round
</button>

<button class="fx-btn fx-btn-warning"
  style="--fx-control-padding-x: 5rem; width: auto;">
  Extra horizontal padding
</button>
  • --fx-control-height button height
  • --fx-control-padding-x horizontal padding
  • --fx-control-padding-y vertical padding
  • --fx-control-border-radius corner radius
  • --fx-border-width and --fx-border-color border styling
  • --fx-control-background-color and --fx-text-color colors
  • --fx-disabled-control-opacity disabled opacity
  • --fx-spinner-svg loading icon
  • --fx-transition animation timing
What the CSS package covers
  • Base. .fx-btn applies flex layout, height (--fx-control-height), padding (--fx-control-padding-x, --fx-control-padding-y), typography, color and background from tokens, border and border-radius (--fx-control-border-radius), and transition (--fx-transition). Cursor and user-select are set for button behavior.
  • Disabled state. The [disabled] selector applies muted text color, opacity (--fx-disabled-control-opacity), cursor not-allowed, and pointer-events: none so the control is non-interactive.
  • Loading state. For [aria-busy="true"], visible text is hidden and a spinner is shown via ::before using the --fx-spinner-svg mask; the accessible label is exposed via ::after from attr(aria-label). Opacity and pointer-events match the disabled state; cursor is wait. RTL reverses the spinner animation direction.
  • Theme variants. Modifier classes .fx-btn-primary, .fx-btn-secondary, .fx-btn-success, .fx-btn-info, .fx-btn-warning, .fx-btn-danger, .fx-btn-light, and .fx-btn-dark set background, border, and text colors from semantic tokens; :hover and loading-state spinner/label colors are included.
  • Focus. Focus styling uses the global focus ring tokens (--fx-focus-ring-outline-width, --fx-focus-ring-outline-offset, --fx-focus-ring-color) unless overridden.
  • Customization tokens. Height, padding, border radius, border width/color, background, text color, disabled opacity, spinner asset, and transition are controlled by the corresponding --fx-* variables documented for the control.
Accessibility notes
  • When the button is in a loading state, set aria-busy="true" and provide a clear aria-label that describes the action in progress (e.g. "Submitting", "Saving").
  • Use the disabled attribute to make the button non-interactive and to prevent submission or activation.
