Button Component

The Button component is used to create interactive buttons.

Base usage
<button type="button" style="width: 150px;" class="mk-btn">Base button</button>
Theme colors
<button type="button" style="width: 150px;" class="mk-btn mk-btn-primary">Primary</button>
<button type="button" style="width: 150px;" class="mk-btn mk-btn-secondary">Secondary</button>
<button type="button" style="width: 150px;" class="mk-btn mk-btn-success">Success</button>
<button type="button" style="width: 150px;" class="mk-btn mk-btn-info">Info</button>
<button type="button" style="width: 150px;" class="mk-btn mk-btn-warning">Warning</button>
<button type="button" style="width: 150px;" class="mk-btn mk-btn-danger">Danger</button>
<button type="button" style="width: 150px;" class="mk-btn mk-btn-light">Light</button>
<button type="button" style="width: 150px;" class="mk-btn mk-btn-dark">Dark</button>
Disabled and loading states
<button type="button" style="width: 150px;" class="mk-btn mk-btn-secondary" disabled>Disabled</button>
<button type="button" style="width: 150px;" class="mk-btn mk-btn-primary" aria-busy="true" aria-label="Submitting">
  Submitting
</button>
Form actions (button type)
<button type="button" style="width: 150px;" class="mk-btn mk-btn-primary">Action</button>
<button type="submit" style="width: 150px;" class="mk-btn mk-btn-success">Submit</button>
<button type="reset" style="width: 150px;" class="mk-btn mk-btn-warning">Reset</button>
  • Always set type explicitly to avoid accidental submits.
  • Use submit and reset only inside forms.
JavaScript helper (busy state)
// Ensure microuikit.js is loaded
const btn = document.getElementById("save-btn");
MicroUIKit.ButtonBusy.enableBusy(btn, "Saving");
setTimeout(() => MicroUIKit.ButtonBusy.disableBusy(btn), 1200);
  • Dispatches microuikit:button-busy on the button element.
  • Provide a readable label for assistive technologies.
Quick customization
<button class="mk-btn mk-btn-success"
  style="--mk-control-height: 3.5rem; --mk-control-border-radius: 999px;">
  Compact & round
</button>

<button class="mk-btn mk-btn-warning"
  style="--mk-control-padding-x: 5rem; width: auto;">
  Extra horizontal padding
</button>
  • --mk-control-height button height
  • --mk-control-padding-x horizontal padding
  • --mk-control-padding-y vertical padding
  • --mk-control-border-radius corner radius
  • --mk-border-width and --mk-border-color border styling
  • --mk-control-background-color and --mk-text-color colors
  • --mk-disabled-control-opacity disabled opacity
  • --mk-spinner-svg loading icon
  • --mk-transition animation timing
What the CSS package covers
  • Base. .mk-btn applies flex layout, height (--mk-control-height), padding (--mk-control-padding-x, --mk-control-padding-y), typography, color and background from tokens, border and border-radius (--mk-control-border-radius), and transition (--mk-transition). Cursor and user-select are set for button behavior.
  • Disabled state. The [disabled] selector applies muted text color, opacity (--mk-disabled-control-opacity), cursor not-allowed, and pointer-events: none so the control is non-interactive.
  • Loading state. For [aria-busy="true"], visible text is hidden and a spinner is shown via ::before using the --mk-spinner-svg mask; the accessible label is exposed via ::after from attr(aria-label). Opacity and pointer-events match the disabled state; cursor is wait. RTL reverses the spinner animation direction.
  • Theme variants. Modifier classes .mk-btn-primary, .mk-btn-secondary, .mk-btn-success, .mk-btn-info, .mk-btn-warning, .mk-btn-danger, .mk-btn-light, and .mk-btn-dark set background, border, and text colors from semantic tokens; :hover and loading-state spinner/label colors are included.
  • Focus. Focus styling uses the global focus ring tokens (--mk-focus-ring-outline-width, --mk-focus-ring-outline-offset, --mk-focus-ring-color) unless overridden.
  • Customization tokens. Height, padding, border radius, border width/color, background, text color, disabled opacity, spinner asset, and transition are controlled by the corresponding --mk-* variables documented for the control.
Accessibility notes
  • When the button is in a loading state, set aria-busy="true" and provide a clear aria-label that describes the action in progress (e.g. "Submitting", "Saving").
  • Use the disabled attribute to make the button non-interactive and to prevent submission or activation.
