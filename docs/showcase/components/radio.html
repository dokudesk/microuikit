Radio Component

The Radio component styles a native radio input with a custom circle and inner dot.

Base usage
<div class="fx-radio-frame">
  <input id="r-a" type="radio" class="fx-radio" name="group" />
  <label for="r-a">Option A</label>
</div>
<div class="fx-radio-frame">
  <input id="r-b" type="radio" class="fx-radio" name="group" checked />
  <label for="r-b">Option B</label>
</div>
  • Use the same name on all radios in a group so only one radio can be selected.
Disabled state
<div class="fx-radio-frame">
    <input id="..." type="radio" class="fx-radio" name="group" disabled />
    <label for="...">Disabled unchecked</label>
</div>
<div class="fx-radio-frame">
  <input id="..." type="radio" class="fx-radio" name="group" disabled checked />
  <label for="...">Disabled checked</label>
</div>
  • --fx-disabled-control-opacity sets the opacity of the radio when it is disabled.
  • --fx-text-muted-color sets the color of the radio when it is disabled.
Readonly state
<div class="fx-radio-frame">
  <input id="..." type="radio" class="fx-radio" name="group" readonly checked />
  <label for="...">Readonly (no pointer events)</label>
</div>
  • readonly disables pointer events so the value cannot be changed by click; use when the value is display-only or controlled elsewhere.
Validation states (invalid / valid)
<div class="fx-radio-frame">
  <input id="..." type="radio" class="fx-radio" name="group-invalid" invalid />
  <label for="...">Invalid</label>
</div>

<div class="fx-radio-frame">
  <input id="..." type="radio" class="fx-radio" name="group-invalid" invalid checked />
  <label for="...">Invalid checked</label>
</div>

<div class="fx-radio-frame">
  <input id="..." type="radio" class="fx-radio" name="group-valid" valid checked />
  <label for="...">Valid</label>
</div>

<div class="fx-radio-frame">
  <input id="..." type="radio" class="fx-radio" name="group-aria-invalid" aria-invalid="true" checked />
  <label for="...">ARIA invalid=true</label>
</div>

<div class="fx-radio-frame">
  <input id="..." type="radio" class="fx-radio" name="group-aria-invalid" aria-invalid="false" />
  <label for="...">ARIA invalid=false</label>
</div>

<div class="fx-radio-frame">
  <input id="..." type="radio" class="fx-radio" name="group-invalid-disabled" invalid disabled />
  <label for="...">Invalid + disabled (unchecked)</label>
</div>

<div class="fx-radio-frame">
  <input id="..." type="radio" class="fx-radio" name="group-invalid-disabled" invalid disabled checked />
  <label for="...">Invalid + disabled (checked)</label>
</div>
  • Use invalid/valid for state-driven validation styling; these states apply semantic border/text colors via --fx-invalid-border-color, --fx-invalid-color, --fx-valid-border-color, and --fx-valid-color.
  • ARIA mapping is fully supported: aria-invalid="true" uses invalid styling, and aria-invalid="false" uses valid styling, matching the visual behavior of invalid/valid.
  • When validation and disabled states are combined, disabled behavior remains dominant for interaction (cursor, pointer-events, opacity), while validation colors are still applied where relevant in the visual state.
Quick customization
<div class="fx-radio-frame" style="--fx-radio-size: 1.25rem;">
  <input id="..." type="radio" class="fx-radio" name="group-customization" />
  <label for="...">Smaller circle</label>
</div>
<div class="fx-radio-frame" style="--fx-radio-size: 2rem; --fx-radio-dot-space: 0.4rem;">
  <input id="..." type="radio" class="fx-radio" name="group-customization" checked />
  <label for="...">Larger circle</label>
</div>

<div class="fx-radio-frame" style="--fx-radio-checked-color: var(--fx-success);">
  <input id="..." type="radio" class="fx-radio" name="group-customization" />
  <label for="...">Success checked color</label>
</div>

<div class="fx-radio-frame" style="--fx-radio-checked-color: var(--fx-warning);">
  <input id="..." type="radio" class="fx-radio" name="group-customization" />
  <label for="...">Warning checked color</label>
</div>

<div class="fx-radio-frame" style="--fx-radio-checked-color: var(--fx-danger);">
  <input id="..." type="radio" class="fx-radio" name="group-customization" />
  <label for="...">Danger checked color</label>
</div>
  • --fx-radio-size sets the size of the circle.
  • --fx-radio-dot-space sets the gap between ring and inner dot.
  • --fx-radio-checked-color sets the color of the checked ring and inner dot.
  • --fx-control-background-color sets the background color of the unselected circle.
  • --fx-border-width sets the width of the border.
  • --fx-border-color sets the color of the border.
  • --fx-focus-ring-* sets the focus outline width, color, and offset.
  • --fx-control-padding-x sets the gap between circle and label.
  • --fx-text-color sets the color of the label.
  • --fx-text-muted-color sets the color of the label when it is disabled.
  • --fx-disabled-control-opacity sets the opacity of the radio when it is disabled.
  • --fx-transition sets the animation.
What the CSS package covers
  • Base. .fx-radio-frame provides the wrapper layout for the native input and its label.
  • Native input. input[type="radio"].fx-radio is visually hidden (clip and opacity) and sized via --fx-radio-size while remaining focusable and announced by assistive technologies.
  • Custom ring and dot. label[for]::before is the ring (size --fx-radio-size, border, background, border-radius: 50%). ::after is the inner dot (size from --fx-radio-size and --fx-radio-dot-space, color --fx-radio-checked-color), revealed when checked via opacity and scale transition.
  • Checked state. :checked + label::before updates the ring border color; :checked + label::after reveals the dot with opacity and scale.
  • Focus. :focus-visible:not(:disabled) + label::before applies the global focus ring (outline and offset from focus-ring tokens).
  • Disabled state. [disabled] + label receives muted color, reduced opacity, cursor not-allowed, and pointer-events: none; the ring and dot use muted colors and opacity.
  • Readonly state. [readonly] and [readonly] + label receive pointer-events: none so the control is non-interactive while the visual state is unchanged.
  • Validation. [invalid] and [aria-invalid="true"] apply invalid label color, ring border color, and checked-dot color via --fx-invalid-*. [valid] and [aria-invalid="false"] apply valid colors via --fx-valid-*.
Accessibility notes
  • Associate a label with each radio via for and matching id so the control is announced and the label click area selects the option.
  • Use the same name for all options in a group so the selection is mutually exclusive and keyboard navigation (arrow keys) works correctly.
  • The native input is visually hidden but remains in the tab order and is announced by screen readers; the custom circle is decorative only.
  • Expose validation state to assistive technologies and drive styling by using the invalid and valid attributes, or aria-invalid="true" and aria-invalid="false".
