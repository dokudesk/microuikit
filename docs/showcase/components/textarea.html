Textarea Component

The Textarea component styles multi-line text fields with support for placeholder, focus, validation (invalid/valid), disabled state, and floating labels.

Base usage
<textarea class="mk-textarea" rows="3" placeholder="Enter text..."></textarea>
Placeholder and focus
<textarea class="mk-textarea" rows="3" placeholder="Default focus border"></textarea>

<textarea class="mk-textarea" rows="3" placeholder="Custom focus border"
  style="--mk-border-color: var(--mk-danger);">
</textarea>
  • --mk-placeholder-color sets the color of the placeholder text.
  • --mk-border-color sets the color of the border when the textarea is focused.
  • --mk-focus-ring-color sets the color of the focus ring when the textarea is focused.
Validation states (invalid / valid)
<textarea class="mk-textarea" rows="2" invalid placeholder="Invalid"></textarea>
<textarea class="mk-textarea" rows="2" valid placeholder="Valid"></textarea>

<textarea class="mk-textarea" rows="2" aria-invalid="true" placeholder="ARIA invalid=true"></textarea>
<textarea class="mk-textarea" rows="2" aria-invalid="false" placeholder="ARIA invalid=false"></textarea>

<textarea class="mk-textarea" rows="2" invalid disabled placeholder="Invalid + disabled"></textarea>
<textarea class="mk-textarea" rows="2" valid disabled placeholder="Valid + disabled"></textarea>
  • Use invalid/valid for state-driven validation styling; these states apply semantic border/text colors via --mk-invalid-border-color, --mk-invalid-color, --mk-valid-border-color, and --mk-valid-color.
  • ARIA mapping is fully supported: aria-invalid="true" uses invalid styling, and aria-invalid="false" uses valid styling, matching the visual behavior of invalid/valid.
  • When validation and disabled states are combined, disabled behavior remains dominant for interaction (opacity and non-interactivity), while validation colors are still applied where relevant in the visual state.
Disabled state
<textarea class="mk-textarea" rows="2" disabled placeholder="Disabled"></textarea>
  • --mk-disabled-control-opacity sets the opacity of the textarea when it is disabled.
Floating label
<div class="mk-textarea-frame">
  <textarea id="..." class="mk-textarea" rows="3" placeholder="Placeholder"></textarea>
  <label for="...">Label</label>
</div>

<div class="mk-textarea-frame">
  <textarea id="..." class="mk-textarea" rows="3" invalid placeholder="Invalid"></textarea>
  <label for="...">Invalid with label</label>
</div>

<div class="mk-textarea-frame">
  <textarea id="..." class="mk-textarea" rows="3" valid placeholder="Valid"></textarea>
  <label for="...">Valid with label</label>
</div>

<div class="mk-textarea-frame">
  <textarea id="..." class="mk-textarea" rows="3" disabled placeholder="Disabled"></textarea>
  <label for="...">Disabled with label</label>
</div>

<div class="mk-textarea-frame">
  <textarea id="..." class="mk-textarea" rows="3" valid disabled placeholder="Valid + Disabled"></textarea>
  <label for="...">Valid + Disabled with label</label>
</div>
  • Use a placeholder so the label can float when the textarea has value or is focused.
  • The label moves up when focused or when textarea is not placeholder-shown.
Quick customization
<textarea class="mk-textarea"
  rows="2" placeholder="Extra padding"
  style="--mk-control-padding-x: 2rem;"></textarea>

<textarea class="mk-textarea"
  rows="3" placeholder="Rounded + subtle background color"
  style="--mk-control-border-radius: 1rem;
         --mk-control-background-color: var(--mk-background-muted-color);">
</textarea>

<textarea class="mk-textarea"
  rows="3" placeholder="Custom colors"
  style="--mk-focus-ring-color: var(--mk-warning);
         --mk-text-color: var(--mk-warning);
         --mk-placeholder-color: var(--mk-text-muted-color);"></textarea>
</textarea>
  • --mk-control-padding-x sets the horizontal padding.
  • --mk-control-padding-y sets the vertical padding.
  • --mk-control-border-radius sets the corner roundness.
  • --mk-border-width sets the border thickness.
  • --mk-border-color sets the border color.
  • --mk-control-background-color sets the background color.
  • --mk-text-color sets the text color.
  • --mk-placeholder-color sets the placeholder color.
  • --mk-focus-ring-color sets the focus/value accent color.
  • --mk-invalid-border-color, --mk-invalid-color, --mk-valid-border-color, and --mk-valid-color sets the validation colors.
  • --mk-disabled-control-opacity sets the opacity of the textarea when it is disabled.
  • --mk-transition sets motion timing for state changes.
What the CSS package covers
  • Base. .mk-textarea applies padding, font, line-height, color, background, border, border-radius, and transition via --mk-control-padding-x/--mk-control-padding-y, --mk-font-*, --mk-text-color, --mk-control-background-color, --mk-border-width, --mk-border-color, --mk-control-border-radius, and --mk-transition.
  • Placeholder and focus. ::placeholder uses --mk-placeholder-color. Inside .mk-textarea-frame, placeholder is transparent so the floating label is visible. Focus updates the border color; the framed textarea has outline: none so the frame reflects focus.
  • Validation and disabled state. [invalid] and [aria-invalid="true"] apply invalid border and text colors via --mk-invalid-* tokens; [valid] and [aria-invalid="false"] apply valid colors via --mk-valid-*. [disabled] applies --mk-text-muted-color and --mk-disabled-control-opacity.
  • Floating-label frame. .mk-textarea-frame provides a bordered container; the inner .mk-textarea is full-width with transparent background and no border. The label is absolutely positioned and animates on :focus and :not(:placeholder-shown) (reduced font size and background patch). Frame border color is driven by :has() selectors for focus, value, invalid, valid, and disabled using the same semantic tokens.
Accessibility notes
  • Associate a visible or off-screen label with the textarea via for and matching id so the control is announced and the label click area activates the field.
  • Set a suitable rows value and retain resize behavior unless layout requirements require it to be disabled.
  • Expose validation state by using the invalid and valid attributes, or aria-invalid="true" and aria-invalid="false", and ensure error or success text is announced to screen readers (e.g. via live regions or aria-describedby).
  • Use aria-describedby to reference helper or hint text when users need format, length, or content guidance.
