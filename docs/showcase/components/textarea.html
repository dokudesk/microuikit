Textarea Component

The Textarea component styles multi-line text fields with support for placeholder, focus, validation (invalid/valid), disabled state, and floating labels.

Base usage
<textarea class="fx-textarea" rows="3" placeholder="Enter text..."></textarea>
Placeholder and focus
<textarea class="fx-textarea" rows="3" placeholder="Default focus border"></textarea>

<textarea class="fx-textarea" rows="3" placeholder="Custom focus border"
  style="--fx-border-color: var(--fx-danger);">
</textarea>
  • --fx-placeholder-color sets the color of the placeholder text.
  • --fx-border-color sets the color of the border when the textarea is focused.
  • --fx-focus-ring-color sets the color of the focus ring when the textarea is focused.
Validation states (invalid / valid)
<textarea class="fx-textarea" rows="2" invalid placeholder="Invalid"></textarea>
<textarea class="fx-textarea" rows="2" valid placeholder="Valid"></textarea>

<textarea class="fx-textarea" rows="2" aria-invalid="true" placeholder="ARIA invalid=true"></textarea>
<textarea class="fx-textarea" rows="2" aria-invalid="false" placeholder="ARIA invalid=false"></textarea>

<textarea class="fx-textarea" rows="2" invalid disabled placeholder="Invalid + disabled"></textarea>
<textarea class="fx-textarea" rows="2" valid disabled placeholder="Valid + disabled"></textarea>
  • Use invalid/valid for state-driven validation styling; these states apply semantic border/text colors via --fx-invalid-border-color, --fx-invalid-color, --fx-valid-border-color, and --fx-valid-color.
  • ARIA mapping is fully supported: aria-invalid="true" uses invalid styling, and aria-invalid="false" uses valid styling, matching the visual behavior of invalid/valid.
  • When validation and disabled states are combined, disabled behavior remains dominant for interaction (opacity and non-interactivity), while validation colors are still applied where relevant in the visual state.
Disabled state
<textarea class="fx-textarea" rows="2" disabled placeholder="Disabled"></textarea>
  • --fx-disabled-control-opacity sets the opacity of the textarea when it is disabled.
Floating label
<div class="fx-textarea-frame">
  <textarea id="..." class="fx-textarea" rows="3" placeholder="Placeholder"></textarea>
  <label for="...">Label</label>
</div>

<div class="fx-textarea-frame">
  <textarea id="..." class="fx-textarea" rows="3" invalid placeholder="Invalid"></textarea>
  <label for="...">Invalid with label</label>
</div>

<div class="fx-textarea-frame">
  <textarea id="..." class="fx-textarea" rows="3" valid placeholder="Valid"></textarea>
  <label for="...">Valid with label</label>
</div>

<div class="fx-textarea-frame">
  <textarea id="..." class="fx-textarea" rows="3" disabled placeholder="Disabled"></textarea>
  <label for="...">Disabled with label</label>
</div>

<div class="fx-textarea-frame">
  <textarea id="..." class="fx-textarea" rows="3" valid disabled placeholder="Valid + Disabled"></textarea>
  <label for="...">Valid + Disabled with label</label>
</div>
  • Use a placeholder so the label can float when the textarea has value or is focused.
  • The label moves up when focused or when textarea is not placeholder-shown.
Quick customization
<textarea class="fx-textarea"
  rows="2" placeholder="Extra padding"
  style="--fx-control-padding-x: 2rem;"></textarea>

<textarea class="fx-textarea"
  rows="3" placeholder="Rounded + subtle background color"
  style="--fx-control-border-radius: 1rem;
         --fx-control-background-color: var(--fx-background-muted-color);">
</textarea>

<textarea class="fx-textarea"
  rows="3" placeholder="Custom colors"
  style="--fx-focus-ring-color: var(--fx-warning);
         --fx-text-color: var(--fx-warning);
         --fx-placeholder-color: var(--fx-text-muted-color);"></textarea>
</textarea>
  • --fx-control-padding-x sets the horizontal padding.
  • --fx-control-padding-y sets the vertical padding.
  • --fx-control-border-radius sets the corner roundness.
  • --fx-border-width sets the border thickness.
  • --fx-border-color sets the border color.
  • --fx-control-background-color sets the background color.
  • --fx-text-color sets the text color.
  • --fx-placeholder-color sets the placeholder color.
  • --fx-focus-ring-color sets the focus/value accent color.
  • --fx-invalid-border-color, --fx-invalid-color, --fx-valid-border-color, and --fx-valid-color sets the validation colors.
  • --fx-disabled-control-opacity sets the opacity of the textarea when it is disabled.
  • --fx-transition sets motion timing for state changes.
What the CSS package covers
  • Base field: .fx-textarea sets the spacing, font, colors, background, border, radius, and transition.
  • Placeholder: ::placeholder sets the placeholder color.
  • State styling: [invalid]/[aria-invalid="true"], [valid]/[aria-invalid="false"], and [disabled] update border/text/opacity with semantic tokens.
  • Floating label: the label animates on :focus and :not(:placeholder-shown), with state-aware colors for invalid/valid/disabled.
Accessibility notes
  • Always associate a label with the textarea (e.g. label[for]).
  • Set a suitable rows value and keep resize behavior unless your layout has a strict reason to lock it.
  • For validation, you can use either invalid/valid or aria-invalid="true"/aria-invalid="false"; keep error/success text announced for screen readers.
  • Use helper text with aria-describedby when users need format, length, or content guidance.
