Collapse Component

The Collapse component toggles content visibility with vertical or horizontal transitions.

Vertical collapse
Toggle panel
Release notes

This panel collapses vertically. 

<button
  type="button"
  class="fx-btn fx-btn-primary"
  data-toggle="collapse"
  data-target="#demo-collapse-vertical"
  aria-expanded="true"
  aria-controls="demo-collapse-vertical">
  Toggle panel
</button>

<a href="#demo-collapse-vertical" 
  class="fx-link fx-link-primary" 
  role="button" data-toggle="collapse" 
  data-target="#demo-collapse-vertical" 
  aria-expanded="true" 
  aria-controls="demo-collapse-vertical">
  Toggle panel
</a>

<div id="demo-collapse-vertical" class="fx-collapse fx-w-100 show" style="max-width: 32rem;">
  <div class="fx-card">
    <div class="fx-card-header"><strong>Release notes</strong></div>
    <div class="fx-card-body">
      <p class="fx-m-0">This panel collapses vertically.</p>
    </div>
  </div>
</div>
  • Use .fx-collapse to collapse the panel vertically.
  • Add .show to the target if the panel should start opened (default is collapsed).

What the CSS package covers
  • Trigger API: Any element with data-toggle="collapse" and data-target="#selector" will toggle the target by adding or removing the .show class when clicked.
  • Vertical collapse: Elements with the .fx-collapse class are hidden by default and expand when .show is applied.
  • Horizontal collapse: Adding .fx-collapse-horizontal animates the panel's width instead of height, following the same collapse flow.
  • Transition variable: The collapse animation uses the CSS variable --fx-transition (applied via .fx-collapsing). Override it on a parent or wrapper element to customize animation duration and easing.
