Checkbox Component

The Checkbox component styles a native checkbox input with a custom visual box and tick icon.

Base usage
<div class="mk-checkbox-frame">
  <input id="cb-base" type="checkbox" class="mk-checkbox" />
  <label for="cb-base">Option</label>
</div>
Checked and unchecked
<div class="mk-checkbox-frame">
  <input id="..." type="checkbox" class="mk-checkbox" />
  <label for="...">Unchecked</label>
</div>

<div class="mk-checkbox-frame">
  <input id="..." type="checkbox" class="mk-checkbox" checked />
  <label for="...">Checked</label>
</div>
  • --mk-checkbox-checked-background-color sets the background color when the checkbox is checked.
  • --mk-checkbox-tick-color sets the color of the tick icon.
Focus-visible
<div class="mk-checkbox-frame">
  <input id="..." type="checkbox" class="mk-checkbox" />
  <label for="...">Focus me</label>
</div>

<div class="mk-checkbox-frame" style="--mk-focus-ring-outline-width: 2px; 
  --mk-focus-ring-color: var(--mk-danger); 
  --mk-focus-ring-outline-offset: 4px;">
  <input id="..." type="checkbox" class="mk-checkbox" />
  <label for="...">Focus me (keyboard or click) with custom focus ring</label>
</div>
  • --mk-focus-ring-outline-width sets the width of the focus ring.
  • --mk-focus-ring-color sets the color of the focus ring.
  • --mk-focus-ring-outline-offset sets the offset of the focus ring.
Disabled state
<div class="mk-checkbox-frame">
  <input id="..." type="checkbox" class="mk-checkbox" disabled />
  <label for="...">Disabled unchecked</label>
</div>

<div class="mk-checkbox-frame">
  <input id="..." type="checkbox" class="mk-checkbox" disabled checked />
  <label for="...">Disabled checked</label>
</div>
  • --mk-disabled-control-opacity sets the opacity of the checkbox when it is disabled.
Readonly state
<div class="mk-checkbox-frame">
  <input id="..." type="checkbox" class="mk-checkbox" readonly checked />
  <label for="...">Readonly (no pointer events)</label>
</div>
  • readonly disables pointer events so the value cannot be toggled by click; use when the value is display-only or controlled elsewhere.
Validation states (invalid / valid)
<div class="mk-checkbox-frame">
  <input id="..." type="checkbox" class="mk-checkbox" invalid />
  <label for="...">Invalid unchecked</label>
</div>

<div class="mk-checkbox-frame">
  <input id="..." type="checkbox" class="mk-checkbox" valid checked />
  <label for="...">Valid checked</label>
</div>

<div class="mk-checkbox-frame">
  <input id="..." type="checkbox" class="mk-checkbox" aria-invalid="true" />
  <label for="...">ARIA invalid=true</label>
</div>

<div class="mk-checkbox-frame">
  <input id="..." type="checkbox" class="mk-checkbox" aria-invalid="false" checked />
  <label for="...">ARIA invalid=false</label>
</div>

<div class="mk-checkbox-frame">
  <input id="..." type="checkbox" class="mk-checkbox" invalid disabled />
  <label for="...">Invalid + disabled (unchecked)</label>
</div>

<div class="mk-checkbox-frame">
  <input id="..." type="checkbox" class="mk-checkbox" invalid disabled checked />
  <label for="...">Invalid + disabled (checked)</label>
</div>
  • Use invalid/valid for state-driven validation styling; these states apply semantic border/text colors via --mk-invalid-border-color, --mk-invalid-color, --mk-valid-border-color, and --mk-valid-color.
  • ARIA mapping is fully supported: aria-invalid="true" uses invalid styling, and aria-invalid="false" uses valid styling, matching the visual behavior of invalid/valid.
  • When validation and disabled states are combined, disabled behavior remains dominant for interaction (cursor, pointer-events, opacity), while validation colors are still applied where relevant in the visual state.
Quick customization
<div class="mk-checkbox-frame" style="--mk-checkbox-size: 1.25rem;">
  <input id="..." type="checkbox" class="mk-checkbox" />
  <label for="...">Smaller box</label>
</div>
<div class="mk-checkbox-frame" style="--mk-checkbox-size: 2rem; --mk-checkbox-border-radius: 6px;">
  <input id="..." type="checkbox" class="mk-checkbox" checked />
  <label for="...">Larger, rounded box</label>
</div>

<div class="mk-checkbox-frame"
     style="--mk-checkbox-checked-background-color: var(--mk-success);
            --mk-checkbox-tick-color: var(--mk-white);">
  <input id="..." type="checkbox" class="mk-checkbox" checked />
  <label for="...">Success palette</label>
</div>

<div class="mk-checkbox-frame"
     style="--mk-checkbox-checked-background-color: var(--mk-warning);
            --mk-checkbox-tick-color: var(--mk-dark);">
  <input id="..." type="checkbox" class="mk-checkbox" checked />
  <label for="...">Warning palette</label>
</div>

<div class="mk-checkbox-frame"
     style="--mk-checkbox-checked-background-color: var(--mk-danger);
            --mk-checkbox-tick-color: var(--mk-light);">
  <input id="..." type="checkbox" class="mk-checkbox" checked />
  <label for="...">Danger palette</label>
</div>
  • --mk-checkbox-size box size
  • --mk-checkbox-border-radius corner radius
  • --mk-checkbox-checked-background-color filled box when checked
  • --mk-checkbox-tick-color tick icon color
  • --mk-checkbox-tick-svg tick mask image
  • --mk-border-width, --mk-border-color, --mk-control-background-color
  • --mk-focus-ring-* focus outline
  • --mk-control-padding-x gap between box and label
  • --mk-text-color, --mk-text-muted-color, --mk-disabled-control-opacity
  • --mk-transition animation
What the CSS package covers
  • Base. .mk-checkbox-frame provides the wrapper layout (margin: 0) for the native input and its label.
  • Native input. input[type="checkbox"].mk-checkbox is visually hidden (clip and opacity) and positioned for accessibility while remaining focusable and announced by assistive technologies.
  • Custom box and tick. label[for]::before is the custom box (size --mk-checkbox-size, border, background --mk-control-background-color, radius --mk-checkbox-border-radius). ::after is the tick (mask --mk-checkbox-tick-svg, color --mk-checkbox-tick-color), shown when checked via opacity and transition.
  • Checked state. :checked + label::before updates background and border; the tick is revealed via ::after opacity.
  • Focus. :focus-visible:not(:disabled) + label::before applies the global focus ring (outline and offset from focus-ring tokens).
  • Disabled state. [disabled] + label receives muted color, reduced opacity, cursor not-allowed, and pointer-events: none; the box and tick pseudo-elements use muted colors and opacity so the control clearly appears disabled.
  • Readonly state. [readonly] and [readonly] + label receive pointer-events: none so the control is non-interactive while the visual state is unchanged.
  • Validation. [invalid] and [aria-invalid="true"] apply invalid label color, box border, and (when checked) box/tick colors via --mk-invalid-*. [valid] and [aria-invalid="false"] apply valid colors via --mk-valid-*.
Accessibility notes
  • Associate a label with the checkbox via for and matching id so the control is announced and the label click area toggles the checkbox.
  • The native input is visually hidden but remains in the tab order and is announced by screen readers; the custom box is decorative only.
  • Expose validation state to assistive technologies and drive styling by using the invalid and valid attributes, or aria-invalid="true" and aria-invalid="false".
