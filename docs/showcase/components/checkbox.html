Checkbox Component

The Checkbox component styles a native checkbox input with a custom visual box and tick icon.

Base usage
<div class="fx-checkbox-frame">
  <input id="cb-base" type="checkbox" class="fx-checkbox" />
  <label for="cb-base">Option</label>
</div>
Checked and unchecked
<div class="fx-checkbox-frame">
  <input id="..." type="checkbox" class="fx-checkbox" />
  <label for="...">Unchecked</label>
</div>

<div class="fx-checkbox-frame">
  <input id="..." type="checkbox" class="fx-checkbox" checked />
  <label for="...">Checked</label>
</div>
  • --fx-checkbox-checked-background-color sets the background color when the checkbox is checked.
  • --fx-checkbox-tick-color sets the color of the tick icon.
Focus-visible
<div class="fx-checkbox-frame">
  <input id="..." type="checkbox" class="fx-checkbox" />
  <label for="...">Focus me</label>
</div>

<div class="fx-checkbox-frame" style="--fx-focus-ring-outline-width: 2px; 
  --fx-focus-ring-color: var(--fx-danger); 
  --fx-focus-ring-outline-offset: 4px;">
  <input id="..." type="checkbox" class="fx-checkbox" />
  <label for="...">Focus me (keyboard or click) with custom focus ring</label>
</div>
  • --fx-focus-ring-outline-width sets the width of the focus ring.
  • --fx-focus-ring-color sets the color of the focus ring.
  • --fx-focus-ring-outline-offset sets the offset of the focus ring.
Disabled state
<div class="fx-checkbox-frame">
  <input id="..." type="checkbox" class="fx-checkbox" disabled />
  <label for="...">Disabled unchecked</label>
</div>

<div class="fx-checkbox-frame">
  <input id="..." type="checkbox" class="fx-checkbox" disabled checked />
  <label for="...">Disabled checked</label>
</div>
  • --fx-disabled-control-opacity sets the opacity of the checkbox when it is disabled.
Readonly state
<div class="fx-checkbox-frame">
  <input id="..." type="checkbox" class="fx-checkbox" readonly checked />
  <label for="...">Readonly (no pointer events)</label>
</div>
  • readonly disables pointer events so the value cannot be toggled by click; use when the value is display-only or controlled elsewhere.
Validation states (invalid / valid)
<div class="fx-checkbox-frame">
  <input id="..." type="checkbox" class="fx-checkbox" invalid />
  <label for="...">Invalid unchecked</label>
</div>

<div class="fx-checkbox-frame">
  <input id="..." type="checkbox" class="fx-checkbox" valid checked />
  <label for="...">Valid checked</label>
</div>

<div class="fx-checkbox-frame">
  <input id="..." type="checkbox" class="fx-checkbox" aria-invalid="true" />
  <label for="...">ARIA invalid=true</label>
</div>

<div class="fx-checkbox-frame">
  <input id="..." type="checkbox" class="fx-checkbox" aria-invalid="false" checked />
  <label for="...">ARIA invalid=false</label>
</div>

<div class="fx-checkbox-frame">
  <input id="..." type="checkbox" class="fx-checkbox" invalid disabled />
  <label for="...">Invalid + disabled (unchecked)</label>
</div>

<div class="fx-checkbox-frame">
  <input id="..." type="checkbox" class="fx-checkbox" invalid disabled checked />
  <label for="...">Invalid + disabled (checked)</label>
</div>
  • Use invalid/valid for state-driven validation styling; these states apply semantic border/text colors via --fx-invalid-border-color, --fx-invalid-color, --fx-valid-border-color, and --fx-valid-color.
  • ARIA mapping is fully supported: aria-invalid="true" uses invalid styling, and aria-invalid="false" uses valid styling, matching the visual behavior of invalid/valid.
  • When validation and disabled states are combined, disabled behavior remains dominant for interaction (cursor, pointer-events, opacity), while validation colors are still applied where relevant in the visual state.
Quick customization
<div class="fx-checkbox-frame" style="--fx-checkbox-size: 1.25rem;">
  <input id="..." type="checkbox" class="fx-checkbox" />
  <label for="...">Smaller box</label>
</div>
<div class="fx-checkbox-frame" style="--fx-checkbox-size: 2rem; --fx-checkbox-border-radius: 6px;">
  <input id="..." type="checkbox" class="fx-checkbox" checked />
  <label for="...">Larger, rounded box</label>
</div>

<div class="fx-checkbox-frame"
     style="--fx-checkbox-checked-background-color: var(--fx-success);
            --fx-checkbox-tick-color: var(--fx-white);">
  <input id="..." type="checkbox" class="fx-checkbox" checked />
  <label for="...">Success palette</label>
</div>

<div class="fx-checkbox-frame"
     style="--fx-checkbox-checked-background-color: var(--fx-warning);
            --fx-checkbox-tick-color: var(--fx-dark);">
  <input id="..." type="checkbox" class="fx-checkbox" checked />
  <label for="...">Warning palette</label>
</div>

<div class="fx-checkbox-frame"
     style="--fx-checkbox-checked-background-color: var(--fx-danger);
            --fx-checkbox-tick-color: var(--fx-light);">
  <input id="..." type="checkbox" class="fx-checkbox" checked />
  <label for="...">Danger palette</label>
</div>
  • --fx-checkbox-size box size
  • --fx-checkbox-border-radius corner radius
  • --fx-checkbox-checked-background-color filled box when checked
  • --fx-checkbox-tick-color tick icon color
  • --fx-checkbox-tick-svg tick mask image
  • --fx-border-width, --fx-border-color, --fx-control-background-color
  • --fx-focus-ring-* focus outline
  • --fx-control-padding-x gap between box and label
  • --fx-text-color, --fx-text-muted-color, --fx-disabled-control-opacity
  • --fx-transition animation
What the CSS package covers
  • Base field: .fx-checkbox-frame wrapper with margin: 0 and layout for input + label.
  • Native input : input[type="checkbox"].fx-checkbox visually hidden (clip, opacity), positioned for accessibility.
  • Custom box: ::before = custom box (size, border, background, border-radius); ::after = tick (mask, color when checked).
  • Checked: :checked + label::before sets the background/border; tick visible via ::after.
  • Focus: :focus-visible:not(:disabled) + label::before sets the outline and offset.
  • Disabled: [disabled] label color/opacity/cursor/pointer-events; box and tick use muted color and opacity.
  • Readonly: [readonly] pointer-events none on input and label.
  • Invalid/Valid: [invalid]/[aria-invalid="true"] and [valid]/[aria-invalid="false"] control label color, box border, and checked box/tick colors.
Accessibility notes
  • Always use a label[for] that matches the input id so the checkbox is properly associated and clickable.
  • The native input is visually hidden but remains focusable and announced by screen readers; the custom box is purely visual.
  • For validation, use invalid (or aria-invalid="true") / valid (or aria-invalid="false") attributes to control the label color, box border, and checked box/tick colors.
