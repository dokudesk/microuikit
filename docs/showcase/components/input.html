Input Component

The Input component styles text fields with support for placeholder, focus, validation (invalid/valid), disabled state, floating labels, and password visibility toggle.

Base usage
<input type="text" class="fx-input" style="width: 50%;" placeholder="Placeholder text" />

<input type="text" class="fx-input" 
  style="width: 50%; --fx-focus-ring-color: var(--fx-danger);" 
  placeholder="Placeholder text (focus to see custom focus ring)"
 />
  • Placeholder uses --fx-placeholder-color.
  • Focus uses --fx-focus-ring-color for border.
Validation states (invalid / valid)
<input type="text" class="fx-input" invalid placeholder="Invalid" value="Error value" />
<input type="text" class="fx-input" valid placeholder="Valid" value="Valid value" />

<input type="text" class="fx-input" aria-invalid="true" placeholder="ARIA invalid=true" value="Error value (aria)" />
<input type="text" class="fx-input" aria-invalid="false" placeholder="ARIA invalid=false" value="Valid value (aria)" />

<input type="text" class="fx-input" invalid disabled placeholder="Invalid + disabled" value="Error value (disabled)" />
<input type="text" class="fx-input" valid disabled placeholder="Valid + disabled" value="Valid value (disabled)" />
  • Set invalid (or aria-invalid="true") / valid (or aria-invalid="false") attribute (e.g. via JS after validation).
  • Colors: --fx-invalid-border-color, --fx-valid-border-color.
  • When both invalid (or aria-invalid="true") / valid (or aria-invalid="false") and disabled are set, the result combines validation border/color with disabled opacity and non-interactivity (see the two examples above).
Disabled state
<input type="text" class="fx-input" disabled placeholder="Disabled" value="Disabled value" />
  • --fx-disabled-control-opacity controls the visual de-emphasis level for disabled inputs.
  • --fx-text-muted-color defines the disabled text color for better contrast consistency across themes.
Floating label (fx-input-frame)
<div class="fx-input-frame">
  <input id="..." type="text" class="fx-input" placeholder="" />
  <label for="...">Label</label>
</div>

<div class="fx-input-frame">
  <input id="..." type="text" class="fx-input" invalid placeholder="" value="Invalid value" />
  <label for="...">Invalid with label</label>
</div>

<div class="fx-input-frame">
  <input id="..." type="text" class="fx-input" valid placeholder="" value="Valid value" />
  <label for="...">Valid with label</label>
</div>

<div class="fx-input-frame">
  <input id="..." type="text" class="fx-input" disabled placeholder="" value="Disabled value" />
  <label for="...">Disabled with label</label>
</div>

<div class="fx-input-frame">
  <input id="..." type="text" class="fx-input" valid disabled placeholder="" value="Valid value (disabled)" />
  <label for="...">Valid + Disabled with label</label>
</div>
  • Use empty placeholder="" so the label can float when the input has value or is focused.
  • Label moves up and shrinks when focused or when input is not placeholder-shown.
  • Invalid/valid/disabled states style the floating label accordingly (see the examples above).
Password with visibility toggle
<div class="fx-input-frame">
  <input id="..." type="password" class="fx-input" placeholder="" />
  <label for="...">Password</label>
  <button type="button" class="fx-toggle-password" aria-controls="..." aria-pressed="false" aria-label="Show password"></button>
</div>

<div class="fx-input-frame" style="max-width: 20rem;">
  <input id="..." type="password" class="fx-input" placeholder="" disabled value="Password (disabled)" />
  <label for="...">Password (disabled)</label>
  <button type="button" class="fx-toggle-password" aria-controls="input-pwd-disabled" aria-pressed="false" aria-label="Show password"></button>
</div>

<div class="fx-input-frame" style="--fx-control-icon-color: #0d6efd; --fx-password-toggle-background-hover-color: rgba(13, 110, 253, 0.15);">
  <input id="..." type="password" class="fx-input" placeholder="" />
  <label for="...">Custom toggle colors</label>
  <button type="button" class="fx-toggle-password" aria-controls="input-pwd-custom" aria-pressed="false" aria-label="Show password"></button>
</div>
  • Add a fx-toggle-password button.
  • aria-controls must reference the target input id.
  • Ensure flexa.js is loaded so the toggle works.
  • Use aria-pressed and aria-label for accessibility.
  • Styling .fx-toggle-password: control icon color with --fx-control-icon-color and hover/focus background with --fx-password-toggle-background-hover-color. Apply these tokens on .fx-input-frame (or a parent), as shown in the third example.
  • When the input has disabled, the toggle is non-interactive (opacity and pointer-events) and reflects the disabled state.
Quick customization
<input class="fx-input" style="--fx-control-height: 3.5rem; --fx-control-border-radius: 999px;" />

<input class="fx-input" style="--fx-control-padding-x: 2rem;" />
  • --fx-control-height sets the input height.
  • --fx-control-padding-x and --fx-control-padding-y control internal spacing.
  • --fx-control-border-radius controls corner roundness.
  • --fx-border-width and --fx-border-color define the field border.
  • --fx-control-background-color, --fx-text-color, and --fx-placeholder-color define surface and text colors.
  • --fx-focus-ring-color controls the focus border color.
  • --fx-invalid-border-color, --fx-invalid-color, --fx-valid-border-color, and --fx-valid-color control validation colors.
  • --fx-disabled-control-opacity controls disabled-state emphasis.
  • --fx-transition sets motion timing for state changes.
  • For password toggle styling, use --fx-control-icon-color for the icon and --fx-password-toggle-background-hover-color for hover/focus background.
What the CSS package covers
  • Base field: .fx-input defines height, padding, typography, text/background, border, radius, and transition using --fx-control-height, --fx-control-padding-*, --fx-control-background-color, --fx-border-width, --fx-border-color, --fx-control-border-radius, and --fx-transition.
  • Placeholder and focus: ::placeholder uses --fx-placeholder-color, and focus border uses --fx-focus-ring-color (with border-color fallback).
  • Validation mapping: [invalid] and [aria-invalid="true"] apply invalid border/text via --fx-invalid-border-color and --fx-invalid-color; [valid] and [aria-invalid="false"] apply valid border/text via --fx-valid-border-color and --fx-valid-color.
  • Disabled state: [disabled] uses muted text color and --fx-disabled-control-opacity.
  • Floating-label frame: .fx-input-frame manages label positioning, focus/value transitions, and state-aware label colors for invalid/valid/disabled.
  • Password toggle: .fx-toggle-password is rendered inside .fx-input-frame; icon color uses --fx-control-icon-color, hover/focus surface uses --fx-password-toggle-background-hover-color, and the icon state follows aria-pressed.
Accessibility notes
  • Always use a label[for] that matches the input id so the input is properly associated and clickable.
  • For validation, use invalid (or aria-invalid="true") / valid (or aria-invalid="false") attributes to control the border/text colors.
  • Password toggle: set aria-pressed and a clear aria-label (e.g. "Show password" / "Hide password").
