Skeleton Component

The Skeleton helper applies a shimmer loading state to an existing element while keeping the element's size and layout intact. Content remains in the DOM but is visually hidden until loading is complete.

Base usage
Loading title
Avatar
<div class="fx-skeleton fx-rounded-pill">Loading title</div>
<div class="fx-skeleton fx-rounded-circle" style="width: 3rem; height: 3rem;">Avatar</div>
  • Apply .fx-skeleton to the same element that already has the final width and height.
  • Text or child content stays in place, so layout does not jump when loading finishes.

Form controls and actions
<input type="text" class="fx-input fx-skeleton"/>        
<button type="button" class="fx-btn fx-btn-primary fx-skeleton" >Continue</button>
<div class="fx-input-frame">
  <input id="skeleton-input" type="text" class="fx-input fx-skeleton" value="Project name"/>
  <label for="skeleton-input">Project name</label>
</div>
<div class="fx-textarea-frame fx-skeleton">
  <textarea class="fx-textarea" rows="3" placeholder="Project description">Project description</textarea>
  <label for="skeleton-textarea">Project description</label>
</div>
<select class="fx-select fx-skeleton">
  <option value="1">Option 1</option>
  <option value="2">Option 2</option>
  <option value="3">Option 3</option>
</select>
  • Use it on controls when the final size is already known and you only want to hide the current content.
  • .fx-skeleton disables pointer interaction during the loading state.
  • Inside .fx-input-frame, the related floating label is hidden automatically when the input uses skeleton state.
Quick customization
Info tone
Sharper corners 
<div class="fx-skeleton fx-rounded-pill"
  style="--fx-skeleton-background-color: var(--fx-background-info);">
  Info tone
</div>
<div class="fx-skeleton fx-rounded-sm"
  style="--fx-skeleton-background-color: var(--fx-background-warning);">
  Sharper corners
</div>
  • Change --fx-skeleton-background-color to alter the skeleton base tone.
  • Set width, height, and border radius on the target element to match the final UI shape.
What the CSS package covers
  • Shimmer surface. .fx-skeleton applies --fx-skeleton-background-color plus an animated gradient shimmer.
  • Preserved layout. Child content is hidden with visibility: hidden, so the element keeps its original footprint.
  • Safe loading state. Text selection and pointer interaction are disabled while skeleton is active.
  • Flexible target. The class can be attached to containers, buttons, inputs, cards, or simple block elements.
  • Keep the real semantic structure in the DOM so screen readers can still understand the page when needed.
  • When content is genuinely unavailable, pair the skeleton state with loading semantics such as aria-busy="true" on the parent region.
