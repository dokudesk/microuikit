Flexa CSS Framework

A lightweight, utility-first CSS framework built for microsystems with minimal UI needs - optimized for multilingual environments and fast performance. Designed with component-based architecture, full RTL/LTR support, WCAG 2.1 accessibility compliance, and powered by CSS Cascade Layers for predictable styling and seamless theme switching.
