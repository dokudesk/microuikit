Input Component Documentation

The Input component styles text fields with support for placeholder, focus, validation (invalid/valid), disabled state, floating labels via fx-input-frame, and password visibility toggle.

Base usage

<input type="text" class="fx-input" placeholder="Enter text..." />

Placeholder and focus

<input type="text" class="fx-input" placeholder="Placeholder text" />
  • Placeholder uses --fx-placeholder-color.
  • Focus uses --fx-focus-ring-color for border.

Validation states (invalid / valid)

<input type="text" class="fx-input" invalid placeholder="Invalid" value="..." />
<input type="text" class="fx-input" valid placeholder="Valid" value="..." />

<!-- Invalid/valid and disabled together -->
<input type="text" class="fx-input" invalid disabled value="..." />
<input type="text" class="fx-input" valid disabled value="..." />
  • Set invalid or valid attribute (e.g. via JS after validation).
  • Colors: --fx-invalid-border-color, --fx-invalid-color, --fx-valid-border-color, --fx-valid-color.
  • When both invalid/valid and disabled are set, the result combines validation border/color with disabled opacity and non-interactivity (see the two examples above).

Disabled state

<input type="text" class="fx-input" disabled placeholder="Disabled" value="..." />
  • Uses --fx-disabled-control-opacity and muted text color.

Floating label (fx-input-frame)

<div class="fx-input-frame">
  <input id="my-input" type="text" class="fx-input" placeholder="" />
  <label for="my-input">Label</label>
</div>

<div class="fx-input-frame">
  <input id="my-input" type="text" class="fx-input" valid disabled placeholder="" value="..." />
  <label for="my-input">Valid + Disabled with label</label>
</div>
  • Use empty placeholder="" so the label can float when the input has value or is focused.
  • Label moves up and shrinks when focused or when input is not placeholder-shown.
  • Invalid/valid/disabled states style the floating label accordingly.

Password with visibility toggle

<div class="fx-input-frame">
  <input id="input-pwd" type="password" class="fx-input" placeholder="" />
  <label for="input-pwd">Password</label>
  <button type="button" class="fx-toggle-password" data-action="input-pwd"
    aria-pressed="false" aria-label="Show password"></button>
</div>

<!-- Example: custom icon and background colors for the toggle -->
<div class="fx-input-frame"
  style="--fx-control-icon-color: #0d6efd;
         --fx-password-toggle-background-hover-color: rgba(13, 110, 253, 0.15);">
  <input id="input-pwd-custom" type="password" class="fx-input" placeholder="" />
  <label for="input-pwd-custom">Custom toggle colors</label>
  <button type="button" class="fx-toggle-password" data-action="input-pwd-custom"
    aria-pressed="false" aria-label="Show password"></button>
</div>
  • Add a fx-toggle-password button.
  • data-action must be the id of the input.
  • Ensure flexa.js is loaded so the toggle works.
  • Use aria-pressed and aria-label for accessibility.
  • Styling fx-toggle-password: icon color — --fx-control-icon-color; background on hover/focus — --fx-password-toggle-background-hover-color. Set these on fx-input-frame (or a parent); see the second example above.
  • When the input has disabled, the toggle is non-interactive (opacity and pointer-events) and reflects the disabled state.

Quick customization

<input class="fx-input"
  style="--fx-control-height: 3.5rem; --fx-control-border-radius: 999px;" />

<input class="fx-input"
  style="--fx-control-padding-x: 2rem;" />
  • --fx-control-height input height
  • --fx-control-padding-x / --fx-control-padding-y padding
  • --fx-control-border-radius corner radius
  • --fx-border-width, --fx-border-color border
  • --fx-control-background-color, --fx-text-color, --fx-placeholder-color
  • --fx-focus-ring-color focus border
  • --fx-invalid-border-color, --fx-invalid-color, --fx-valid-border-color, --fx-valid-color
  • --fx-disabled-control-opacity disabled opacity
  • --fx-transition animation
  • Password toggle: --fx-control-icon-color (icon), --fx-password-toggle-background-hover-color (hover/focus)

What the CSS package covers

  • Base: .fx-input — height, padding, font, color, background, border, border-radius, transition.
  • Placeholder: ::placeholder color via --fx-placeholder-color.
  • Focus: border color via --fx-focus-ring-color.
  • Validation: [invalid] and [valid] — border and text color.
  • Disabled: [disabled] — muted color and opacity.
  • Frame: .fx-input-frame — floating label layout and transitions (focus / not placeholder-shown / invalid / valid / disabled).
  • Password toggle: .fx-toggle-password — position, icon (eye / eye-off via aria-pressed), hover/focus.

Accessibility notes

  • Always associate a label with the input (e.g. label[for] or aria-label).
  • For validation, use invalid/valid in addition to aria-invalid and announce errors to screen readers.
  • Password toggle: set aria-pressed and a clear aria-label (e.g. "Show password" / "Hide password").
