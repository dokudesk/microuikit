Select Component Documentation

The Select component styles a native <select> with custom appearance, arrow icon, and support for focus, validation (invalid/valid), disabled state, and multiple selection. Use fx-select-frame with fx-select-arrow for a themeable arrow (mask + --fx-select-arrow-color) so it matches light/dark mode.

Base usage

<select class="fx-select">
  <option>Option A</option>
  <option>Option B</option>
  <option>Option C</option>
</select>
  • Without fx-select-frame, the select uses the browser’s native appearance.

With frame and arrow (mask-based)

<div class="fx-select-frame">
  <select id="sel-frame" class="fx-select">
    <option value="">Choose…</option>
    <option>Apple</option>
    <option>Banana</option>
    <option>Cherry</option>
  </select>
  <span class="fx-select-arrow" aria-hidden="true"></span>
</div>
  • Arrow is rendered with mask + --fx-select-arrow-color so it follows the theme (e.g. dark mode).
  • fx-select-arrow is decorative and has pointer-events: none; clicks go to the select.

Validation states (invalid / valid)

<select class="fx-select" invalid>...</select>
<select class="fx-select" valid>...</select>

<select class="fx-select" invalid disabled>...</select>
<select class="fx-select" valid disabled>...</select>
  • Set invalid or valid (e.g. via JS after validation). Uses --fx-invalid-border-color, --fx-invalid-color, --fx-valid-border-color, --fx-valid-color.
  • When both invalid/valid and disabled are set, border and opacity follow the disabled state.

Disabled state

<select class="fx-select" disabled>...</select>
  • Uses --fx-disabled-control-opacity and muted text color.

Multiple selection

<select class="fx-select" multiple>
  <option>Option 1</option>
  <option selected>Option 2</option>
  ...
</select>

<select class="fx-select" multiple invalid>
  <option>Option 1</option>
  <option selected>Option 2</option>
  ...
</select>

<select class="fx-select" multiple disabled>
  <option>Option 1</option>
  <option selected>Option 2</option>
  ...
</select>
  • No arrow is shown for multiple; selected options use --fx-select-selected-option-text-color and --fx-select-selected-option-background-color.
  • Inside fx-select-frame, the arrow element is hidden when the select has multiple.

Optgroups

<div class="fx-select-frame">
  <select class="fx-select">
    <optgroup label="Fruits">
      <option>Apple</option>
      <option>Banana</option>
    </optgroup>
    <optgroup label="Vegetables">...</optgroup>
  </select>
  <span class="fx-select-arrow" aria-hidden="true"></span>
</div>

Quick customization

  • --fx-control-height, --fx-control-padding-x, --fx-control-padding-y, --fx-control-border-radius
  • --fx-border-width, --fx-border-color, --fx-control-background-color, --fx-text-color
  • --fx-focus-ring-color focus border
  • --fx-select-arrow-color arrow color (frame only; follows theme in dark mode)
  • --fx-select-selected-option-text-color, --fx-select-selected-option-background-color for selected option
  • --fx-invalid-*, --fx-valid-*, --fx-disabled-control-opacity
  • --fx-transition

What the CSS package covers

  • Base: .fx-select — size, padding, font, color, background, border, focus, invalid, valid, disabled; option, option:checked; multiple (no arrow, different padding). Without frame, native browser appearance.
  • Frame: .fx-select-frame — wrapper; .fx-select inside gets appearance: none and padding for the arrow when .fx-select-arrow is present; .fx-select-arrow — decorative arrow (mask + --fx-select-arrow-color); arrow hidden when select is multiple.

Accessibility notes

  • Associate a label[for] with the select’s id so it’s announced and clickable.
  • Use invalid/valid together with aria-invalid and provide error/success text for screen readers.
  • fx-select-arrow has aria-hidden="true" so it’s ignored by assistive tech.
