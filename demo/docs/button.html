Button Component Documentation

The Button component is used to create interactive buttons. It is a basic component that can be used to create a button.

Base usage

<button type="button" class="fx-btn">Base button</button>

Theme colors

<button class="fx-btn fx-btn-primary">Primary</button>
<button class="fx-btn fx-btn-secondary">Secondary</button>
<button class="fx-btn fx-btn-success">Success</button>
<button class="fx-btn fx-btn-info">Info</button>
<button class="fx-btn fx-btn-warning">Warning</button>
<button class="fx-btn fx-btn-danger">Danger</button>
<button class="fx-btn fx-btn-light">Light</button>
<button class="fx-btn fx-btn-dark">Dark</button>

Disabled and loading states

<button class="fx-btn fx-btn-secondary" disabled>Disabled</button>
<button class="fx-btn fx-btn-primary" aria-busy="true" aria-label="Submitting">
  Submitting
</button>

Form actions (button type)

<button type="button" class="fx-btn fx-btn-primary">Action</button>
<button type="submit" class="fx-btn fx-btn-success">Submit</button>
<button type="reset" class="fx-btn fx-btn-warning">Reset</button>
  • Always set type explicitly to avoid accidental submits.
  • Use submit and reset only inside forms.

JavaScript helper (busy state)

// Ensure flexa.js is loaded
const btn = document.getElementById("save-btn");
Flexa.ButtonBusy.enableBusy(btn, "Saving");
setTimeout(() => Flexa.ButtonBusy.disableBusy(btn), 1200);
  • Dispatches flexa:button-busy on the button element.
  • Provide a readable label for assistive technologies.

Button-style links

Link as button 
<a class="fx-btn fx-btn-info" href="#">Link as button</a>

Quick customization

<button class="fx-btn fx-btn-success"
  style="--fx-control-height: 2.5rem; --fx-control-border-radius: 999px;">
  Compact & round
</button>
  • --fx-control-height button height
  • --fx-control-padding-x horizontal padding
  • --fx-control-padding-y vertical padding
  • --fx-control-border-radius corner radius
  • --fx-border-width and --fx-border-color border styling
  • --fx-control-background-color and --fx-text-color colors
  • --fx-disabled-control-opacity disabled opacity
  • --fx-spinner-svg loading icon
  • --fx-transition animation timing

Accessibility notes

  • For loading, always set aria-busy and a readable aria-label.
  • Use disabled for non-interactive buttons.
  • When using an a tag, ensure the destination is meaningful.
