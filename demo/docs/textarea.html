Textarea Component Documentation

The Textarea component styles multi-line text fields with support for placeholder, focus, validation (invalid/valid), disabled state, and floating labels via fx-textarea-frame.

Base usage

<textarea class="fx-textarea" rows="3" placeholder="Enter text..."></textarea>

Placeholder and focus

<textarea class="fx-textarea" rows="3" placeholder="Placeholder"></textarea>
  • Placeholder uses --fx-placeholder-color.
  • With fx-textarea-frame, the frame border uses --fx-focus-ring-color when the textarea is focused or has value.

Validation states (invalid / valid)

<textarea class="fx-textarea" invalid>...</textarea>
<textarea class="fx-textarea" valid>...</textarea>

<textarea class="fx-textarea" invalid disabled>...</textarea>
<textarea class="fx-textarea" valid disabled>...</textarea>
  • Set invalid or valid (e.g. via JS after validation). Uses --fx-invalid-border-color, --fx-invalid-color, --fx-valid-border-color, --fx-valid-color.
  • When both invalid/valid and disabled are set, the result combines validation border/color with disabled opacity and non-interactivity.

Disabled state

<textarea class="fx-textarea" disabled>...</textarea>
  • Uses --fx-disabled-control-opacity and muted text color.

Floating label (fx-textarea-frame)

<div class="fx-textarea-frame">
  <textarea id="my-ta" class="fx-textarea" rows="3" placeholder=""></textarea>
  <label for="my-ta">Label</label>
</div>

<div class="fx-textarea-frame">
  <textarea id="my-ta" class="fx-textarea" rows="3" disabled placeholder=""></textarea>
  <label for="my-ta">Disabled with label</label>
</div>

<div class="fx-textarea-frame">
  <textarea id="my-ta2" class="fx-textarea" rows="3" valid disabled placeholder=""></textarea>
  <label for="my-ta2">Valid + Disabled with label</label>
</div>
  • Use empty placeholder="" so the label can float when the textarea has value or is focused.
  • Label moves up when focused or when textarea is not placeholder-shown; invalid/valid/disabled style the label and frame border.

Quick customization

<textarea class="fx-textarea"
  style="--fx-control-padding-x: 2rem;"></textarea>
  • --fx-control-padding-x / --fx-control-padding-y padding
  • --fx-control-border-radius corner radius
  • --fx-border-width, --fx-border-color border
  • --fx-control-background-color, --fx-text-color, --fx-placeholder-color
  • --fx-focus-ring-color focus border
  • --fx-invalid-*, --fx-valid-*, --fx-disabled-control-opacity
  • --fx-transition animation

What the CSS package covers

  • Base: .fx-textarea — padding, font, color, background, border, border-radius, transition, placeholder, focus, invalid, valid, disabled.
  • Frame: .fx-textarea-frame — wrapper with border and padding; textarea inside is transparent with no border; floating label (focus / not placeholder-shown / invalid / valid / disabled); frame border color follows state via :has().

Accessibility notes

  • Always associate a label with the textarea (e.g. label[for] or aria-label).
  • For validation, use invalid/valid in addition to aria-invalid and announce errors to screen readers.
