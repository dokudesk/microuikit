Flexa CSS Framework

Version 1.0.0

A lightweight, utility-first CSS framework built for microsystems with minimal UI needs — optimized for multilingual environments and fast performance. Designed with component-based architecture, full RTL/LTR support, WCAG 2.1 accessibility compliance, and powered by CSS Cascade Layers for predictable styling and seamless theme switching.

Developed by DokuDesk

Components

Button
Theme colors, disabled, loading spinner (aria-busy), form types
Input
Single-line text, floating label, password show/hide toggle
Checkbox
Custom box and tick, focus ring, readonly, invalid/valid
Radio
Custom circle and dot, grouped by name, validation states
Textarea
Multi-line text, floating label, frame border by state
Select
Native select, frame with arrow, multiple selection, optgroups
